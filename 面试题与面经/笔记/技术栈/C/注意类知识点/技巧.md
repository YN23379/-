## 键盘技巧
```
# 移动光标
Ctrl + A              # 行首
Ctrl + E              # 行尾  
Ctrl + ←/→            # 按单词移动
Home/End              # 行首/行尾

# 编辑操作
Ctrl + D              # 删除当前字符/选中内容
Ctrl + K              # 删除到行尾
Ctrl + W              # 删除前一个单词
Ctrl + /              # 注释/取消注释

# 选择文本
Shift + ←/→/↑/↓       # 选择文本
Ctrl + Shift + ←/→    # 按单词选择
```
## 一维数组下标转成二维数组
对于m*n的矩阵
$a[i]=matrix[⌊i/n⌋][i mod n]$`$
代码实现：`a[i]=matrix[i/n][i%n]`
