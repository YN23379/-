## open/close

对于类似打开文件的函数，它们都占有对应的一个文件描述符，每一个进程的文件描述符是有上限的
每一次open都需要对应调用一次close
close的作用是：
1. **释放内核资源**：每个打开的文件在内核中都有对应的数据结构（file结构体）
    
2. **回收文件描述符**：文件描述符是进程级的有限资源
    
3. **确保数据持久化**：对于写入操作，close()会触发缓冲区刷盘

也为了避免资源泄露，
```c
// 必须close的：
open() → close()
socket() → close() 
opendir() → closedir()
fopen() → fclose()
mmap() → munmap()

// 不需要close的：
malloc() → free()  // 用户态内存
pthread_create() → pthread_join()  // 线程资源
```
