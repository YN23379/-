# i.MX95 19x19 EVK 到手操作计划

> **目的**：这块板子（IMX95LPD5EVK-19）是找 NXP 借来换掉 FRDM-IMX95-PRO 的，
> **官方资料在 `C:\Users\chen\Desktop\资料\IMX95_19_19_EVK`**。
> 本文是"拿到板子后按什么顺序做什么"的操作计划，每步都标了官方依据。
>
> **⚠️ 板子很贵（约 1170 美元），且是借的，操作前先读第五节「安全注意事项」。**

## 〇、先认清：EVK 和 Pro 板差在哪

**这不是同一块板子的两个版本，是两块不同的板子。** 之前 Pro 板上的很多经验**不能直接照搬**。

| 项目 | FRDM-IMX95-PRO（旧的） | **IMX95LPD5EVK-19（新）** |
|---|---|---|
| 板型 | 单板 | **SOM + 底板（Base Board）两块插在一起** |
| 调试串口 | USB Type-C (J22) + **CH9114F** 四通道 | USB Type-C (**J31**) + **FT4232H** 四通道 |
| 调试口引脚 | 无裸针脚 | 同样无裸针脚（J31 是 Type-C） |
| **JTAG** | ❌ **只有测试点，无座** | ✅ **有 10-pin JTAG 座（J30）** |
| 启动开关 | **SW4**[1:4] | **SW7**[1:4] |
| 电源 | 板电源口 | **J5**（9-pin DC 座，12V/13.33A，160W）+ **SW4** 电源开关 |
| 内存 | 16GB | 16GB（SOM 上） |
| eMMC | 32GB | **64GB** |
| 出厂的 Linux | 有 | **有**（eMMC 里预装 Linux BSP） |

> **最大差异：EVK 有 JTAG 座（J30）**。这是 `要求.txt` 第 7 条要的东西，
> Pro 板上一直因为没有 JTAG 座而卡住，**换 EVK 后这条路直接通了**。

## 一、开箱先做这 4 件事（不上电）

**① 清点配件**（对照 QSG Table 1，`IMX95LPD5EVK19QSG.pdf` 第 5 页）

| 应包含 | 说明 |
|---|---|
| EVK 主板 | SOM + 底板 |
| 电源适配器 | **12V / 13.33A，160W**，9-pin DC 插头 |
| USB Type-C 线 | 2 根（USB 3.0 A/M 转 Type-C，1 米） |
| **散热片** | 2 片：7×5.28×12mm、9×7.3×12mm（带导热胶） |
| 快速上手手册 | QSG |

> **⚠️ 散热片必须装！** 官方专门有一份《Heatsink Installation Guide》，
> 而且 A55 满载发热不小。**没装散热片不要长时间跑高负载。**

**② 装散热片**（官方有单独手册，在 `nxp.com/iMX95LPD5EVK-19` 下载）

- 两片规格不同，**对号入座**，别装错位置
- 带导热胶，撕掉保护膜再贴
- **一次贴准**，反复撕会破坏导热胶

**③ 目视检查**

- SOM 与底板之间两个高密度连接器（**J1/J2/J3/J5**，DF40TC-120DP-0.4V）**是否插到位**
- 有没有运输造成的元件脱落、排针歪斜
- **先别上电**

**④ 拍照留档**（借来的板子，这一步很重要）

- 整板俯视/仰视各一张
- 两个板对插处一张
- **万一后面出问题，能证明是原有状态还是操作导致**

## 二、第一次上电（验证板子是好的）

**目标**：只确认原厂 Linux 能起来，**先不要跑任何 Harpoon**。

### 接线（就 3 根）

```text
① 调试串口：USB Type-C 线 → 板子 J31 → 电脑 USB
② 电源：适配器 9-pin → 板子 J5
③ （可选）HDMI 显示器：需要 IMX-MIPI-HDMI 转接板 + J14
```

> **J31 不是普通 USB 口**，它是调试口（FT4232H 桥），
> 电脑上会**枚举出 4 个 COM 口**。

### 装驱动

FT4232H **需要装 FTDI 驱动**（`https://www.ftdichip.com`）。
装好后插 J31，设备管理器里应出现 **4 个 COM 口**。

**COM 口对应关系**（`UM12022` Table 50，`官方资料明确说明`）：

| FT4232H 通道 | 用途 | 对应 SoC 串口 |
|---|---|---|
| **Channel A** | 默认 **M7** 调试；也可切 JTAG | **UART3**（TXD/RXD 与 `GPIO_IO14`/`GPIO_IO15` 复用） |
| Channel B | 板上 I2C 主控（温度传感器、电源监测） | — |
| **Channel C** | **A55 调试** | **UART1** |
| **Channel D** | **M33 调试** | **UART2** |

> **注意**：**A55 的 console 在 Channel C（UART1）**，参数 115200-8-N-1。
> 这一点要现场确认——**4 个 COM 口挨个开一遍**，找到出 `U-Boot>` / `login:` 的那个。

### 启动

1. **确认 SW7 拨码** = eMMC 启动

   | SW7[1-4] | 模式 |
   |---|---|
   | **x010** | **uSDHC1 8-bit eMMC 5.1（默认）** ← 用这个 |
   | x001 | Serial downloader（USB，配合 UUU） |
   | x011 | uSDHC2 4-bit SD3.0 |
   | x100 | FlexSPI Serial NOR |

   （`1 = ON`，`0 = OFF`；`x` 那位无关）

2. **插调试串口线到 J31**（电脑上打开对应 COM 口，115200-8-N-1）
3. **打开 SW4 电源开关**
4. **看串口**：应能看到 `U-Boot` → kernel 启动日志 → `login:`

**成功标志**：串口出现 `imx95-19x19-lpddr5-evk` 字样、能登录进去。
**失败就停手**，对照 `UM12022` 查，别硬试。

### 第一次上电就要记下来的东西

```text
1. 4 个 COM 口分别是什么（哪个出 U-Boot）
2. 串口打印的板名/机器名 = ________（应为 imx95-19x19-lpddr5-evk）
3. 内核版本 = ________
4. MemTotal = ________（未做任何设置时，应接近 16GB）
5. eMMC 容量 = ________
```

## 三、Harpoon 复现（板子确认没问题之后）

### 3.1 这次会顺很多

**关键：这块板子就是 Harpoon 包的对应板**（包名 `HS_v3.5_IMX95-19X19-LPDDR5-EVK`）。
之前 Pro 板上的三个坑**全部消失**：

| Pro 板的坑 | EVK 上 |
|---|---|
| 手工 `setenv jh_root_mem` / `jh_clk` 绕 | ✅ **不用了**，官方有 `imx95-19x19-evk-harpoon.dtb` |
| 缺 `-root.dtb` 文件 | ✅ **有**（包内自带 `imx95-19x19-evk-harpoon.dtb`、`imx95-19x19-evk-root.dtb`） |
| cell 是 EVK 的、板子是 Pro 的，对不上 | ✅ **对上了** |
| inmate console 没输出 | ✅ **预期正常**（EVK 的 SM 配置给了 guest cell LPUART3） |

### 3.2 U-Boot 里改成官方的做法

**EVK 上用官方方式**（UG10170 §4.2）：

```bash
U-Boot > setenv jh_root_dtb imx95-19x19-evk-harpoon.dtb
U-Boot > run jh_mmcboot
```

> `jh_mmcboot` 会自动设 `jh_clk` 和 `jh_root_mem`，**不用手敲**。
> 想持久化（可选）：`setenv bootcmd 'run jh_mmcboot'` + `saveenv`。

### 3.3 跑 FreeRTOS

```bash
# Linux 里
modprobe jailhouse
jailhouse enable /usr/share/jailhouse/cells/imx95.cell
jailhouse cell create /usr/share/jailhouse/cells/imx95-harpoon-freertos.cell
jailhouse cell load freertos /usr/share/harpoon/inmates/freertos/rt_latency.bin -a 0xf0000000
jailhouse cell start freertos
```

**这次要重点看**：inmate 的 console **应该能打印**（`INFO: hello_func : Hello world.` 之类）。

> 详细步骤见 [[10-项目/FRDM-IMX95-PRO/Harpoon复现|Harpoon 复现：手把手操作]]
> （流程通用，只需把"手工设内存"改成上面的官方方式）。

### 3.4 EVK 上要重点验证的三件事

| # | 验证什么 | 为什么重要 |
|---|---|---|
| 1 | **inmate console 有输出** | 证明 Pro 板上的问题确实是板级适配导致的 |
| 2 | **跑 `hello_world.bin`**（不只是 `rt_latency`） | 官方 §4.3 明确写了它该打印什么，**最容易判断成功** |
| 3 | **官方 `harpoon_set_configuration.sh` + `systemctl start harpoon` 方式** | Pro 板上我们是手敲命令，**这次试官方方式**，看有没有差别 |

## 四、JTAG 调试（`要求.txt` 第 7 条，EVK 上可做）

**这是 Pro 板做不到、EVK 能做的事。**

### 硬件

- **J30**：2×5-pin Samtec `FTSH-105-01-L-DV-K` 座（标准 10-pin JTAG）
- 引脚定义（`UM12022` Table 52，`官方资料明确说明`）：

| Pin | 信号 | 说明 |
|---|---|---|
| 1 | **VTREF** | 参考电压（给调试器探目标电压） |
| 2 | JTAG_TMS | TAP 状态 |
| 3 | GND | 地 |
| 4 | JTAG_TCK | TAP 时钟 |
| 5 | GND | 地 |
| 6 | JTAG_TDO | TAP 数据出 |
| 7 | GND | 地 |
| 8 | JTAG_TDI | TAP 数据入 |
| 9 | GND | 地 |
| 10 | **CON_JTAG_RST_B** | 系统复位 |

### 接 J-Link 前必须注意的两件事

**① JTAG 与 UART5 复用——SW1 必须 OFF**

> 官方原文：`The JTAG and UART5 signals are multiplexed, therefore, to use JTAG debug,
> switch (SW1) must be set to OFF to disconnect the UART5 signals with the M.2 connector.`

**SW1 默认就是 off**，但**用之前确认一遍**。

**② 片内 FT4232H JTAG 会和外部 JTAG 抢——靠 VTREF 自动切换**

| 条件 | 谁在用 JTAG |
|---|---|
| `RC_SEL = H`，**VTREF = OFF** | **FT4232H 的远程 JTAG** 生效 |
| `RC_SEL = L`，**VTREF = ON** | **外部 JTAG（J30）** 生效（默认） |

**接 J-Link 时 VTREF 要接上**（J-Link 会输出参考电压），这样才切到外部 JTAG。

### 待确认项

- **VTREF / DAP I/O 电平是 1.8V 还是 3.3V**？→ **必须先量再接**，接错可能损坏芯片
- J-Link 型号是否支持 i.MX95（Cortex-A55 + EL3）
- 是否需要 ATF/U-Boot 配合、halt 时机

> Pro 板那篇调研里的问题（`JTAG与SWD接口调研.md`）**在 EVK 上大部分能直接回答**，
> 因为**有座、有明确引脚定义**。

## 五、⚠️ 安全注意事项（借来的贵板子，务必看）

### 上电前

1. **电源只能用原装适配器**（12V/13.33A）。**不要用别的电源**，电压/极性不对会烧板
2. **散热片必须装好**再上电，尤其要跑负载
3. **插拔 SOM 前必须断电**，且注意防静电（先摸接地金属）
4. **J31 是调试口**，别当成普通 USB 口插别的东西

### 操作中

5. **不要热插拔** SOM 与底板之间那两个高密度连接器
6. **JTAG 接线前先量 VTREF 电平**，别直接按 3.3V 接
7. **改 SW7 拨码时先断电**
8. **不要用手直接摸 SOM 上的芯片和连接器**（静电）

### 万一手滑

9. **不要自己拆、不要自己修**。这是借的板子，出问题**立刻联系 NXP（Dongbo Wang）**说明情况
10. 手上还有 Pro 板的话——**在 EVK 完全确认好之前，先别急着寄回去**
