
# 开发环境
### Shell

Shell是一个**命令解释器**，它是用户与Linux/Unix内核之间的桥梁。
用于接收并执行用户输入的命令。
执行脚本（一系列命令的集合）。
提供编程功能，如变量、循环、条件判断。
常见：Bash, Zsh, Ksh, Csh等。
#### bash
shell的一种（**Bourne-Again SHell**）
是**最流行、最常用**的一种，是大多数Linux发行版和macOS的默认Shell。

### Makefile
Makefile是一个**文本文件**，它包含了如何**编译和链接**一个程序的规则，用 `make` 工具来使用。
主要用于**智能增量编译**，自动话地完成编译过程
