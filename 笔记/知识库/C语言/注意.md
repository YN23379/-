在C语言中，`malloc`返回的是`void*`类型，在C语言中`void*`可以自动转换为任何其他指针类型，所以**强制转换是可选的**。
```c
// 这两种写法都是正确的：
Trie* ret = malloc(sizeof(Trie));          // 现代C风格（推荐）
Trie* ret = (Trie*)malloc(sizeof(Trie));   // 传统C风格
```
## 循环

`for(i=1; i<=n; i++)` 循环体执行几次？
**项数** = (末项-首项)/公差 + 1，有等于才+1，没等于就不加，这是循环体次数，条件表达式就在此基础+1
