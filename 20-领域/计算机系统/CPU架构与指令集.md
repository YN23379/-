## 设计
指令集设计
- **CISC**: **C**omplex **I**nstruction **S**et **C**omputer (复杂指令集计算机)
    
- **RISC**: **R**educed **I**nstruction **S**et **C**omputer (精简指令集计算机)



**存储结构不同。**
- 冯诺依曼：程序和数据在同一内存空间，共用总线
- 哈佛：程序存储器和数据存储器分开，独立总线访问

|特性|**冯诺依曼架构**|**哈佛架构**|
|---|---|---|
|**存储结构**|程序和数据共享存储空间|程序和数据分开存储|
|**总线**|单总线（冯·诺依曼瓶颈）|双总线（指令+数据）|
|**访问方式**|串行访问|并行访问|
|**性能**|较低|较高|
|**成本**|较低|较高|

**嵌入式系统多用哈佛架构**：
1. **性能**：指令和数据可同时读取，避免总线竞争
2. **实时性**：适合实时控制（如DSP、单片机）
3. **安全性**：程序区只读，防止数据覆盖代码



### 架构
目前最常见的四大架构是：**x86、ARM、MIPS、RISC-V**。它们的核心区别在于指令集和设计理念。

#### **1. x86 (CISC代表)**
```c
// 设计哲学：强大而复杂的单条指令
MOV AX, [BX+SI+0x1234] // 一条指令完成：地址计算+内存读取
```

- **主导者**：Intel, AMD
    
- **主要领域**：**个人电脑、服务器、高性能计算**
    
- **特点**：
    
    - 指令长度不固定，功能强大
        
    - 硬件电路复杂，功耗较高
        
    - 极强的向后兼容性（甚至能跑40年前的软件）
- **现状**：在桌面和服务器市场近乎垄断

#### **2. ARM (RISC代表)**
```c
// 设计哲学：简单规整的指令集
LDR R1, [R2, #0x10]  // 加载：地址=R2+0x10
ADD R3, R1, R4        // 计算：R3 = R1 + R4
```

- **主导者**：ARM公司（只设计架构，不生产芯片）
    
- **主要领域**：**移动设备、嵌入式系统、物联网**
    
    - 你的手机、平板、智能手表
        
    - 你的Orange Pi开发板
        
    - 几乎所有现代嵌入式设备
        
- **特点**：
    
    - 指令长度固定（32位或64位）
        
    - 功耗极低，能效比优秀
        
    - 通过授权模式，众多厂商可生产ARM芯片
#### **3. MIPS (经典RISC)**

```c
// 设计哲学：极简主义
LW $t0, 0x1000($zero)  // 从内存加载
ADD $t2, $t0, $t1      // 加法运算
```

- **主要领域**：**路由器、网络设备、早期嵌入式系统**
    
- **特点**：
    
    - 非常干净、优雅的设计
        
    - 曾是大学计算机体系结构课程的教学典范
        
- **现状**：逐渐被ARM取代，但在特定领域仍有使用

#### **4. RISC-V (新兴开源RISC)**
```c
// 设计哲学：完全开源、可扩展
ADD x5, x6, x7    // 标准整数指令
CUSTOM_AI x8, x9  // 可自定义的专用指令
```

- **特点**：**完全开源**，任何公司可免费使用和修改
    
- **主要领域**：**新兴IoT设备、学术研究、定制芯片**
    
- **优势**：
    
    - 无授权费用
        
    - 可针对特定应用添加自定义指令
        
    - 得到谷歌、华为、西部数据等大厂支持


32位CPU通常有32位地址总线
寻址空间 = 2³² = 4GB
但注意：有些32位CPU地址总线可能更宽（如ARM Cortex-M3是32位架构，但地址总线可以外扩）
处理数据长度可以是8位，16位，32位等

- 常见的RISC架构（如ARM、MIPS）通常有32个通用寄存器
- 如ARM的R0-R31（包括PC和SP）
- 但x86架构（也是32位）只有8个通用寄存器
- 所以这个说法**不绝对**，但很多32位CPU确实是32个寄存器
