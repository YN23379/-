# 排序算法

> 本篇整理自公开技术文章与经典教材，来源见文末。

## 复杂度与稳定性总览

**先看这张表再背细节**——面试最爱问"哪个稳定、哪个 O(nlogn)"：

| 排序算法 | 平均时间复杂度 | 最差时间复杂度 | 空间复杂度 | 稳定性 |
| :--- | :--- | :--- | :--- | :--- |
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(1) | 数组不稳定、链表稳定 |
| 插入排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n·log₂n) | O(n²) | O(log₂n) | 不稳定 |
| 堆排序 | O(n·log₂n) | O(n·log₂n) | O(1) | 不稳定 |
| 归并排序 | O(n·log₂n) | O(n·log₂n) | O(n) | 稳定 |
| 希尔排序 | O(n·log₂n) | O(n²) | O(1) | 不稳定 |
| 计数排序 | O(n+m) | O(n+m) | O(n+m) | 稳定 |
| 桶排序 | O(n) | O(n) | O(m) | 稳定 |
| 基数排序 | O(k·n) | O(n²) | — | 稳定 |

**三条记忆锚点**：

1. **稳定的**：冒泡、插入、归并、计数、桶、基数——"插冒归计桶基"。
2. **O(n·log₂n) 三兄弟**：快排、堆排、归并；其中**快排最差会退化到 O(n²)**，堆排最稳定但常数大，归并费空间但稳定。
3. **非比较排序**（计数/桶/基数）能突破 O(n·log₂n) 下界，但要求数据是整数/范围有限。

### 稳定性是什么、为什么重要

稳定性 = 相等的元素排序后**相对次序不变**。

- 对纯整数无所谓；但**多关键字排序必须稳定**：先按"成绩"排，再按"姓名"稳定排，才能得到"同姓名按成绩"的结果。
- 选择排序为什么"数组不稳定、链表稳定"：数组实现用**交换**会跨越相等元素，链表实现用**头插/接链**就不会。

## 冒泡排序

**原理**：相邻元素两两比较，把最大的"冒"到最后。

```c
void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; ++i)
        for (int j = 0; j < n - i - 1; ++j)
            if (a[j] > a[j+1]) {
                int tmp = a[j];
                a[j] = a[j+1];
                a[j+1] = tmp;
            }
}
```

## 选择排序

**原理**：每趟从未排序区间选最小（大）的，放到已排序区间末尾。

```c
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[minIndex]) minIndex = j;
        int tmp = a[i]; a[i] = a[minIndex]; a[minIndex] = tmp;
    }
}
```

## 插入排序

**原理**：像抓扑克牌——每张新牌从后往前比较，插到合适位置。**数据基本有序时接近 O(n)**，这是它相对冒泡/选择的核心优势。

```c
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j+1] = a[j];
            j--;
        }
        a[j+1] = key;
    }
}
```

## 快速排序

**原理**：选基准 → 小的丢前面、大的丢后面 → 左右两半递归。**分治法典型**。

```c
void quickSort(int a[], int low, int high) {
    if (low >= high) return;
    int first = low, last = high;
    int key = a[first];
    while (first < last) {
        while (first < last && a[last] >= key) last--;
        if (first < last) a[first++] = a[last];
        while (first < last && a[first] <= key) first++;
        if (first < last) a[last--] = a[first];
    }
    a[first] = key;
    quickSort(a, low, first - 1);
    quickSort(a, first + 1, high);
}
```

**要点**：

- 平均 O(n·log₂n)，但**已有序时退化到 O(n²)**（每次划分只少一个元素）——避免办法是**随机取基准**或三数取中。
- 不稳定；空间 O(log₂n) 是递归栈。

## 堆排序

**原理**：建大顶堆 → 堆顶（最大）与末尾交换 → 堆大小减一、重新调整 → 循环。

```c
void maxHeapify(int arr[], int start, int end) {
    int dad = start, son = dad * 2 + 1;
    while (son <= end) {
        if (son + 1 <= end && arr[son] < arr[son+1]) son++;
        if (arr[dad] > arr[son]) return;
        int tmp = arr[dad]; arr[dad] = arr[son]; arr[son] = tmp;
        dad = son; son = dad * 2 + 1;
    }
}
void heapSort(int arr[], int len) {
    for (int i = len / 2 - 1; i >= 0; i--)   /* 建堆 */
        maxHeapify(arr, i, len - 1);
    for (int i = len - 1; i > 0; i--) {      /* 取顶、缩堆 */
        int tmp = arr[0]; arr[0] = arr[i]; arr[i] = tmp;
        maxHeapify(arr, 0, i - 1);
    }
}
```

**要点**：最坏也是 O(n·log₂n)、空间 O(1)——是"最差情况最稳"的 O(nlogn)，但不稳定、缓存不友好（跳跃访问）。

## 归并排序

**原理**：分到只剩一个 → 两两合并有序序列。**分治 + 稳定**。

```c
void merge(int a[], int tmp[], int l, int m, int r) {
    int i = l, j = m + 1, k = l;
    while (i <= m && j <= r)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];  /* <= 保证稳定 */
    while (i <= m) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (i = l; i <= r; i++) a[i] = tmp[i];
}
void mergeSort(int a[], int tmp[], int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSort(a, tmp, l, m);
    mergeSort(a, tmp, m + 1, r);
    merge(a, tmp, l, m, r);
}
```

**要点**：稳定、最坏也是 O(n·log₂n)，代价是 O(n) 辅助空间。**外部排序（大文件排序）的基础**。

## 希尔排序

**原理**：按增量分组做插入排序，增量逐轮缩小到 1。**插入排序的分组加速版**。

```c
void shellSort(int a[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2)
        for (int i = gap; i < n; i++) {
            int tmp = a[i];
            int j;
            for (j = i; j >= gap && a[j - gap] > tmp; j -= gap)
                a[j] = a[j - gap];
            a[j] = tmp;
        }
}
```

**要点**：不稳定；比直接插入快得多，因为**大步长时移动距离长，小步长时序列已基本有序**。

## 计数排序（非比较）

**原理**：统计每个值出现次数，再按序展开。**不是比较排序**，可突破 O(n·log₂n)。

**适用前提**：整数、值域 [0, k] 且 k 不能太大。

```
步骤：找最大值 → 计数数组 C 记每个值出现次数 → C 前缀累加（得到排名）
     → 逆序回填目标数组（逆序保证稳定性）
```

## 桶排序（非比较）

**原理**：按值域分桶，桶内各自排序（通常用插入排序），最后按桶序拼接。值为 i 的进 i 号桶。

**适用前提**：数据分布均匀；极端分布（全部落一个桶）退化成桶内排序算法的复杂度。

## 基数排序（非比较）

**原理**：按"位"从低位到高位做多轮**稳定排序**（通常每轮用计数/桶排序）。

**要点**：O(k·n)，k 是最大位数。适合手机号、身份证等**定长多关键字**数据。

## 面试高频追问

- **快排最坏什么时候发生？** 已有序/逆序且取首元素为基准 → 退化为 O(n²)。规避：随机基准、三数取中。
- **为什么工业界常用快排而不是堆排？** 快排顺序访问、缓存友好、常数小；堆排跳跃访问、缓存不友好。
- **什么场景必须稳定排序？** 多关键字排序、数据库 ORDER BY、外部排序归并。
- **10 万个 0~100 的整数怎么排最快？** 计数排序 O(n+k)，不是快排。
