# 原理图基础与阅读方法

## 原理图的作用

原理图用于表达电路中各个元器件的电气连接关系和功能关系。它不表示元器件在电路板上的实际位置，也不表示 PCB 走线的真实形状。阅读原理图时，主要关注信号或电源从哪里来，经过什么器件，最后连接到哪里。

## 常见元器件标号

| 标号 | 英文名称 | 中文名称 | 常见作用 |
|---|---|---|---|
| J | Connector | 连接器 | USB、排针、插座、扩展接口 |
| U | Integrated Circuit | 集成电路、芯片 | 电源管理、串口转换、处理器等 |
| R | Resistor | 电阻 | 分压、限流、上拉、下拉、反馈 |
| C | Capacitor | 电容 | 滤波、去耦、储能、耦合 |
| L | Inductor | 电感 | DC/DC 储能、滤波、抑制噪声 |
| D | Diode | 二极管 | 整流、保护、发光、指示 |
| Q | Transistor | 三极管或 MOSFET | 开关、放大、电源控制 |
| Y | Crystal/Oscillator | 晶振或振荡器 | 为芯片提供时钟 |
| SW | Switch | 开关 | 电源开关、启动模式选择 |
| K | Push Button | 按键 | 复位、启动控制、功能输入 |
| F | Fuse | 保险丝 | 过流保护 |
| TP | Test Point | 测试点 | 测量电压或波形 |
| FB | Ferrite Bead | 磁珠 | 电源滤波和噪声隔离 |
| LED | Light Emitting Diode | 发光二极管 | 状态指示 |

例如 `J11` 表示原理图中编号为 11 的连接器，`U44` 表示编号为 44 的芯片。编号由原理图设计者分配，不能根据编号推断器件型号或功能。

## 原理图中的网络名

网络名是电气连接的标识。同一个网络名在不同页面出现时，通常表示这些位置电气相连，即使页面之间没有画出一根连续的导线。

例如：

- `VBUS_IN` 表示进入板子的输入电源总线。
- `VCC_5V0` 表示 5.0 V 电源网络。
- `VDD_3V3` 表示 3.3 V 电源网络。
- `UART1_TX` 表示 UART1 的发送信号。
- 网络名后的方括号数字通常表示该网络还出现在其他页面。

同一个电压值不一定是同一条电源。`VCC_DCDC1_5V` 和 `VCC_DCDC2_5V` 虽然都为 5 V，但网络名不同，说明设计上属于不同电源支路。

## 阅读一条电源链路的步骤

1. 先找输入端，例如连接器、适配器、电池或 USB 供电端。
2. 记录输入网络名和输入电压范围。
3. 沿着网络名或箭头寻找第一个转换器。
4. 记录转换器的芯片编号、输入、输出、使能和电源正常信号。
5. 根据输出网络名继续搜索，寻找下一级稳压器或负载开关。
6. 找到最终负载，例如处理器、内存、USB 接口或扩展接口。
7. 再回到详细电路页，检查电感、电容、反馈电阻和保护器件。

## FRDM-IMX95-PRO 供电阅读示例

先从第 3 页 `PWR TREE` 的左侧开始，找到 `USB C SNK PD` 和 `VBUS_IN 12-20V`。这是电源树的输入位置。然后沿着 `VBUS_IN` 追踪到多个 `DCDC BUCK` 功能块，得到不同的输出电源，例如 `VCC_DCDC1_5V`、`VCC_DCDC2_5V`、`VCC_12V`、`VDD_3V3_K1` 和 `VDD_3V3_K2`。

继续沿输出网络向右，可以看到这些电源分别供给 LPDDR5、eMMC、MicroSD、USB、以太网、M.2 和扩展接口。第 3 页只是电源架构总览，具体的 DC/DC 芯片和外围电路还要根据输出网络名跳转到详细页面。

## 从接口追到功能芯片的示例

以供电接口为例：

1. 在板卡图中找到 `J11`，确认它是 USB-C 供电连接器。
2. 在原理图中搜索 `J11`，查看连接器的引脚和相邻芯片。
3. 找到 USB PD 控制器 `U44 PTN5110`。
4. 查看 USB-C 的 CC 信号如何连接到 PD 控制器。
5. 查看 PD 控制器输出的 `USB_PD_VBUS` 如何连接到 `VBUS_IN`。
6. 回到第 3 页，继续追踪 `VBUS_IN` 后面的 DC/DC 电源链。

以调试串口为例：

1. 找到 `J22`，它是 USB-C 调试连接器。
2. 顺着 USB 数据线找到 `U67 CH9114F`。
3. 查看 CH9114F 的四路 UART 分别连接到哪个处理器核心。
4. 在电脑上看到的四个 COM 口，就是 CH9114F 将这些 UART 通道转换成 USB 后提供的接口。

## 第一次阅读原理图的范围

第一次不需要阅读全部电阻和电容。建议顺序如下：

1. 看板卡框图，知道处理器、内存、存储器和接口的位置。
2. 看电源树，知道输入电压和主要电源轨。
3. 看供电接口和电源控制芯片，弄清楚板子怎样上电。
4. 看调试串口，弄清楚电脑怎样获得启动日志。
5. 看启动配置，弄清楚处理器从 eMMC、SD 或 NOR Flash 的哪一个设备启动。
6. 根据实际任务再看 UART、I2C、SPI、GPIO 和目标外设。
