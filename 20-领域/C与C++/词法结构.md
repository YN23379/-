# 关键字


## `override` 
`override` 是 **C++11** 引入的关键字，用于**显式声明**一个成员函数**重写（覆盖）了基类中的虚函数。

|功能|说明|
|---|---|
|**明确意图**|告诉编译器和代码阅读者：这个函数就是要覆盖基类的虚函数|
|**编译时检查**|如果该函数**并没有**覆盖任何基类虚函数，编译器会**报错**，防止你“以为在重写但实际没重写”|
|**防止错误**|捕获因函数签名不匹配导致的意外重载而非重写|
`override` 要求**所有签名要素一致**，否则编译报错
