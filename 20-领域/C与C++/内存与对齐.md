## 结构体对齐
- 计算结构体大小
    
- 如何优化结构体内存布局
    
- `#pragma pack`的作用和风险


1.数据在内存中的地址必须是其大小的整数倍
2.结构体总大小是其最宽成员的整数倍
每个成员从自身大小的整数倍地址开始
最后补填充到最宽成员的整数倍

**例子**：

```c
struct S1 {        // sizeof = 12 字节
    char a;        // 偏移0
    // 填充3字节
    int b;         // 偏移4  
    char c;        // 偏移8
    // 填充3字节
};

```
在Hi3861项目中，网络协议包需要用`#pragma pack(1)`取消对齐
否则`sizeof(结构体)`会错误，导致MQTT数据解析出错

---

## 为什么网络编程必须用 `#pragma pack(1)`

#### 网络编程中必须使用`#pragma pack(1)`的原因

在网络协议、文件格式、硬件寄存器这些**跨系统、跨平台、字节精确**的场景中，必须禁用对齐
因为会对数据的解析和发送造成严重影响
