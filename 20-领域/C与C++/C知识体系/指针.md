#指针



## 指针运算
### 算术运算

c的指针算术运算只限于两种形式
1.指针±整数，标准定义这种形式值用于指向数组中某元素的指针，结果的类型也是指针
也适用于使用malloc函数动态分配获得的内存
让指针指向数组第一个元素之前或者最后一个元素之后是合法的，但是对这个指针间接访问可能失败
2.指针-指针，只有当两个指着都指向同一数组中的元素时才允许从一个指针减去另一个指针


### 关系运算
对指针执行关系运算也是有限制的
可以使用<,>,≥,≤对两个指针进行比较，`p>q,p<&value[0]`
标准允许指向数组元素的指针与指向数组最后元素后面的那个内存位置的指针进行比较，但不允许与指向数组第一个元素之前的那个内存位置的指针进行比较,虽然大多数的c编译器不会报错，但总有会无法执行的。
如vp指向了`value[0]`前面的内存，而`vp>&value[0]`是作为循环的条件的话，那么这次表达式的值是未定义的，可能会循环失败




## 引用和指针
引用是c++的概念，c里没有
指针是一个存储地址的变量，
引用是变量的别名
**引用是"安全"的指针，指针是"灵活"的引用**
```c
// 指针：存储地址的变量
int value = 10;
int* ptr = &value;   // ptr 是一个指针，存储 value 的地址

// 引用：变量的别名
int& ref = value;    // ref 是 value 的引用（别名）
```


|特性|指针|引用|
|---|---|---|
|**本质**|变量，存储地址|别名，不是独立变量|
|**内存占用**|占用内存（通常4/8字节）|不额外占用内存（编译时符号）|
|**初始化**|可以不初始化（危险！）|**必须初始化**（绑定到已有对象）|
|**可变性**|可指向不同对象|**一旦绑定，不可改变**|
|**空值**|可赋值为 nullptr/NULL|**不能为空**|
|**操作符**|`*` 解引用，`&` 取地址|直接使用，像原变量|
|**多级**|支持多级指针（int**）|只有一级引用|
|**算术运算**|支持指针算术（ptr++, ptr--）|不支持|
