在C语言中，`malloc`返回的是`void*`类型，在C语言中`void*`可以自动转换为任何其他指针类型，所以**强制转换是可选的**。
```c
// 这两种写法都是正确的：
Trie* ret = malloc(sizeof(Trie));          // 现代C风格（推荐）
Trie* ret = (Trie*)malloc(sizeof(Trie));   // 传统C风格
```
## 循环

`for(i=1; i<=n; i++)` 循环体执行几次？
**项数** = (末项-首项)/公差 + 1，有等于才+1，没等于就不加，这是循环体次数，条件表达式就在此基础+1
即走了项数步
## 短路求值（Short-circuit Evaluation）

1. 先检查 `fast != NULL`
    
2. 如果 `fast` 是 `NULL`，立即返回 `false`，**不会执行 `fast->next`**
    
3. 如果 `fast` 不是 `NULL`，才检查 `fast->next != NULL`
    

**安全原因**：确保在访问 `fast->next` 之前，`fast` 一定不是空指针。
不能是`while(fast->next != NULL && fast != NULL)`，执行该语句可能出现段错误

## 宏定义

`#define SWAP(a, b) do { int tmp = (a); (a) = (b); (b) = tmp; } while (0)`
使用的是do -while(0)结构，宏定义是直接替换，如果没有这个结构结果会导致出错
```
if (condition)
    SWAP(x, y);  
else
展开后
if (x > y)
    { int tmp = (x); (x) = (y); (y) = tmp; };  // 注意这里有两个分号！
else
    printf("no swap\n");
❌ 语法错误 因为有多于的分号在if else之间导致语法错误
不过也可以在这种情况下用大括号把SWAP宏定义括起来，但有时候会忘记括号
```
使用do while(0)
- **更简洁**：使用者无需记住特殊规则
    
- **更安全**：避免忘记加括号导致的错误
    
- **更通用**：适用于所有上下文（if、while、三元运算符等）

```
if (condition)
    SWAP(x, y);  // 展开后：if (condition) do { ... } while (0); ✅ 正确
else

SWAP(x, y);  // 分号是必须的，do-while结构需要分号
```
而且在宏定义使用时避免使用++，--，会导致多次嵌套调用
```
SWAP(nums[left],nums[right]); left++; right--; ✅
SWAP(nums[left++],nums[right--]); ❌
```
