## 基础
C++ 完全支持面向对象的程序设计，包括面向对象开发的四大特性：

- **封装（Encapsulation）**：封装是将数据和方法组合在一起，对外部隐藏实现细节，只公开对外提供的接口。这样可以提高安全性、可靠性和灵活性。
    
- **继承（Inheritance）**：继承是从已有类中派生出新类，新类具有已有类的属性和方法，并且可以扩展或修改这些属性和方法。这样可以提高代码的复用性和可扩展性。
    
- **多态（Polymorphism）**：多态是指同一种操作作用于不同的对象，可以有不同的解释和实现。它可以通过接口或继承实现，可以提高代码的灵活性和可读性。
    
- **抽象（Abstraction）**：抽象是从具体的实例中提取共同的特征，形成抽象类或接口，以便于代码的复用和扩展。抽象类和接口可以让程序员专注于高层次的设计和业务逻辑，而不必关注底层的实现细节。


标准的 C++ 由三个重要部分组成：
- 核心语言，提供了所有构件块，包括变量、数据类型和常量，等等。
- C++ 标准库，提供了大量的函数，用于操作文件、字符串等。
- 标准模板库（STL），提供了大量的方法，用于操作数据结构等。


通过编辑器创建的文件通常称为源文件，源文件包含程序源代码。
C++ 程序的源文件通常使用扩展名` .cpp、.cp `或 `.c`。

### 语法
C++ 程序可以定义为**对象的集合**，这些对象通过调用彼此的方法进行交互。
- **对象 -** 对象具有状态和行为。例如：一只狗的状态 - 颜色、名称、品种，行为 - 摇动、叫唤、吃。对象是类的实例。
- **类 -** 类可以定义为描述对象 行为/状态 的 模板/蓝图。
- **方法 -** 从基本上说，一个方法表示一种行为。一个类可以包含多个方法。可以在方法中写入逻辑、操作数据以及执行所有的动作。
- **即时变量 -** 每个对象都有其独特的即时变量。对象的状态是由这些即时变量的值创建的。

 'g++ hello.cpp '，输入回车，编译代码。如果代码中没有错误，命令提示符会跳到下一行，并生成 `a.out` 可执行文件。

每个语句必须以分号结束，它表明一个逻辑实体的结束。
语句块是一组使用大括号括起来的按逻辑连接的语句。
C++ 不以行末作为结束符的标识


### 标识符
C++ 标识符是用来标识变量、函数、类、模块，或任何其他用户自定义项目的名称。一个标识符以字母 A-Z 或 a-z 或下划线 _ 开始，后跟零个或多个字母、下划线和数字（0-9）。
C++ 标识符内不允许出现标点字符，比如 @、& 和 %。C++ 是区分大小写的编程语言。


## 注意

在 C++ 中，**默认参数必须从右向左连续赋值**。也就是说，一旦某个参数指定了默认值，其右边的所有参数都必须有默认值。
```cpp
void func(int a, int b = O, int c);
void func(int a = O, int b, int c);
void func(int a, int b, int c = O);
```
只有第三个正确，第一个和第二个违反了“从右向左连续”的规则，



#### 类的定义与继承

- **定义基类（无继承）**：  
    `class 类名 { 成员变量; 成员函数; };`
    
    - _示例_：`class Base { ... };`
        
- **定义派生类（继承自基类）**：  
    `class 派生类名 : 继承方式 基类名 { 新增成员; };`
    
    - _示例_：`class Derived : public Base { ... };`
        
    - **继承方式**：通常用 `public`，表示派生类公开继承基类的公有成员。
        

#### 2. 构造函数与析构函数

- **构造函数（Construction）**：
    
    - 函数名必须与**类名完全相同**，无返回值（不写 `void`）。
        
    - 在创建对象时**自动调用**，用于初始化成员变量。
        
    - _示例_：`class Base { public: Base() { ... } };`
        
- **析构函数（Destruction）**：
    
    - 函数名为 `~` 加类名（如 `~Base()`），无返回值，无参数。
        
    - 在对象销毁时**自动调用**，用于释放资源（如内存清理）。
        
    - _示例_：`class Derived { public: ~Derived() { ... } };`
        

#### 3. 虚函数（Virtual Function）

- **定义**：在成员函数声明前添加关键字 **`virtual`**。
    
    - _示例_：`virtual void virtualFunction() = 0;`
        
    - 其中 `= 0` 表示该函数为**纯虚函数**，当前类为**抽象类**（不可直接实例化对象）。
        
- **作用（多态）**：允许通过基类指针调用派生类重写（`override`）的版本。
    

#### 4. 核心安全规则（对应考题考点）

**规则**：**在构造函数或析构函数中，绝对不应直接或间接调用虚函数。**

- **原因（书面化原理）**：
    
    - 派生类对象在**构造期间**，基类部分先于派生类部分构造。此时派生类部分尚未初始化，虚函数表尚未完全建立，调用虚函数只会执行基类版本，多态失效。
        
    - 派生类对象在**析构期间**，派生类部分先于基类部分销毁。此时调用虚函数的行为是**未定义（Undefined Behavior）**，可能导致程序崩溃。
        
- **识别违规代码（考试盲选标准）**：
    
    1. 找到类名与函数名相同的函数（如 `Base()`、`Derived()`）或带有 `~` 的函数（如 `~Derived()`）。
        
    2. 检查其函数体内是否调用了带有 `virtual` 关键字的函数。
        
    3. **若满足上述两点，即为违规代码。**
        
    4. 普通成员函数（如 `void nonVirtualFunction()`）内调用虚函数是**合法**的，前提是该普通函数不会在构造或析构阶段间接被调用。
