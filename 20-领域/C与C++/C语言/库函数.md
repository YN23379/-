## stat结构体 函数
```c
#include <sys/types.h>   
#include <sys/stat.h>  
#include <unistd.h>

  
int stat(const char *pathname, struct stat *buf)
```
pathname：用于指定一个需要查看属性的文件路径。
buf：struct stat 类型指针，用于指向一个 struct stat 结构体变量。调用 stat 函数的时候需要传入一个 struct stat 变量的指针，获取到的文件属性信息就记录在 struct stat 结构体中。
返回值：成功返回 0；失败返回-1，并设置 error。
```c
#include <sys/types.h> 
#include <sys/stat.h> 
#include <unistd.h> 
int fstat(int fd, struct stat *buf);
```
第一个参数 fd 表示文件描述符，
buf：struct stat 类型指针，用于指向一个 struct stat 结构体变量。调用 stat 函数的时候需要传入一个 struct stat 变量的指针，获取到的文件属性信息就记录在 struct stat 结构体中。
返回值：成功返回 0；失败返回-1，并设置 error。
```c
#include <sys/types.h> 
#include <sys/stat.h> 
#include <unistd.h> 
int lstat(const char *pathname, struct stat *buf); 
```
pathname：用于指定一个需要查看属性的文件路径。
buf：struct stat 类型指针，用于指向一个 struct stat 结构体变量。调用 stat 函数的时候需要传入一个 struct stat 变量的指针，获取到的文件属性信息就记录在 struct stat 结构体中。
返回值：成功返回 0；失败返回-1，并设置 error。

```c
struct stat 
{ 
 dev_t st_dev; /* 文件所在设备的 ID */ 
 ino_t st_ino; /* 文件对应 inode 节点编号 */ 
 mode_t st_mode; /* 文件对应的模式 */ 
 nlink_t st_nlink; /* 文件的链接数 */ 
 uid_t st_uid; /* 文件所有者的用户 ID */ 
 gid_t st_gid; /* 文件所有者的组 ID */ 
 dev_t st_rdev; /* 设备号（指针对设备文件） */ 
 off_t st_size; /* 文件大小（以字节为单位） */ 
 blksize_t st_blksize; /* 文件内容存储的块大小 */ 
 blkcnt_t st_blocks; /* 文件内容所占块数 */ 
 struct timespec st_atim; /* 文件最后被访问的时间 */ 
 struct timespec st_mtim; /* 文件内容最后被修改的时间 */ 
 struct timespec st_ctim; /* 文件状态最后被改变的时间 */
};
```
st_dev：该字段用于描述此文件所在的设备。不常用，可以不用理会。
st_ino：文件的 inode 编号。 st_mode：该字段用于描述文件的模式，譬如文件类型、文件权限都记录在该变量中
st_nlink：该字段用于记录文件的硬链接数，也就是为该文件创建了多少个硬链接文件。链接文件可以 分为软链接（符号链接）文件和硬链接文件，关于这些内容后面再给大家介绍。
st_uid、st_gid：此两个字段分别用于描述文件所有者的用户 ID 以及文件所有者的组 ID，后面再给大家 介绍。
st_rdev：该字段记录了设备号，设备号只针对于设备文件，包括字符设备文件和块设备文件，不用理会。
st_size：该字段记录了文件的大小（逻辑大小），以字节为单位。
st_atim、st_mtim、st_ctim：此三个字段分别用于记录文件最后被访问的时间、文件内容最后被修改的时 间以及文件状态最后被改变的时间，都是 struct timespec 类型变量


`stat` 通过路径获取文件信息；`fstat` 通过已打开的文件描述符获取；`lstat` 对于符号链接，它返回链接本身的信息而不是链接指向的文件。在检查可能为符号链接的文件时，用 `lstat` 更安全。

读取文件大小：

|特性|`fseek` + `ftell`|`stat`|
|---|---|---|
|**性能**|需要打开文件、寻址、关闭|直接读取inode信息，**更快**|
|**准确性**|可能受文件流缓冲影响|直接获取文件系统记录，**更准确**|
|**并发安全**|如果文件正在被修改，结果可能不准确|原子操作，**更安全**|
|**功能**|只能获取大小|可获取**权限、时间、inode**等丰富信息|
|**资源消耗**|需要文件描述符|不需要打开文件，**资源开销小**|
|**适用范围**|普通文件|文件、目录、设备文件等**所有类型**|

## rename
用于**重命名文件或目录**的函数。
把 **old_filename** 所指向的文件名改为 **new_filename**。
```c
int rename(const char *old_filename, const char *new_filename)
```
- **old_filename** -- 原始文件名（包含路径时需提供完整路径）。
- **new_filename** -- new_filename：新文件名（同样可以包含路径）。

返回值
- 0 ：执行成功（文件/目录重命名成功）。
- 非 0 ：执行失败（常见错误原因有权限不足、文件不存在、目标已存在等）。

old_filename文件必须存在，否则会返回错误。
如果目标文件 new_filename 已经存在，不同系统的处理方式可能不同：
- 在大多数 Unix/Linux 上，rename() 会 直接覆盖 目标文件。
- 在 Windows 上，若目标文件存在，rename() 会 失败。

不能跨不同的挂载点（分区/设备）重命名。
  
  
## <stdio.h>
### printf类
#### `%*s   %.*s`
`%*s`
**在 `scanf` 中**：**忽略读取**。带 `*` 的格式符会匹配输入但**不赋值**给任何变量。
```c
scanf("%d%*s", &a, b); // 输入 "12 abc"：a=12, "abc"被读取后丢弃，b不变
```
**在 `printf` 中**：**动态宽度**。`*` 对应一个整型参数指定**输出宽度**。
```c
printf("%*s", 10, "hi"); // 输出 "        hi" (占10位，左补空格)
```

`%*.s`
**仅用于 `printf`**：**动态精度**。控制**最大输出字符数**。
```c
printf("%.*s", 3, "hello"); // 输出 "hel" (只输出前3个字符)
```

|格式符|在 `scanf` 中|在 `printf` 中|
|---|---|---|
|`%*s`|读取后丢弃|动态字段宽度|
|`%.*s`|无效|动态精度(最大长度)|
|`%*d`|读取后丢弃|动态字段宽度|
|`%.*f`|无效|动态小数位数|
|`%*.*f`|无效|动态宽度和精度|
**`%[总宽度].[精度]f`**
- **总宽度**：整个输出占多少字符（可选）
    
- **精度**：小数点后保留几位（可选）

```c
printf("%2f", 3.14159);    // 输出 "3.141590" (实际是 %f)
识别错误格式。缺少点号会被当作普通 %f 处理。

printf("%3.4f", 3.14159);  // 输出 "3.1416" (宽度不够，按实际输出)
printf("%8.4f", 3.14159);  // 输出 "  3.1416" (占8位，左补空格)
```

#### `snprintf()`
```c
int snprintf ( char * str, size_t size, const char * format, ... );
```

用于格式化输出字符串，并将结果写入到指定的缓冲区，与 sprintf() 不同的是，snprintf() 会限制输出的字符数，避免缓冲区溢出。
如果格式化后的字符串长度超过了 size-1，则 snprintf() 只会写入 size-1 个字符，并在字符串的末尾添加一个空字符（\0）以表示字符串的结束。
- **str** -- 目标字符串，用于存储格式化后的字符串的字符数组的指针。
- **size** -- 字符数组的大小。
- **format** -- 格式化字符串。
- **...** -- 可变参数，可变数量的参数根据 format 中的格式化指令进行格式化。
**返回值是一个整数：**

- 如果成功，返回将要写入的字符数（不包括结尾的空字符），即使这个值大于 size。
    
- 如果发生编码错误，返回负值。

使用[vsnprintf](https://so.csdn.net/so/search?q=vsnprintf&spm=1001.2101.3001.7020)()用于向一个字符串缓冲区打印[格式化字符串](https://so.csdn.net/so/search?q=%E6%A0%BC%E5%BC%8F%E5%8C%96%E5%AD%97%E7%AC%A6%E4%B8%B2&spm=1001.2101.3001.7020)，且可以限定打印的格式化字符串的最大长度。

参数format：格式化限定字符串

参数arg：可变长度参数列表

返回：如果没有发生截断，则代表成功打印到sbuf中的字符的个数，不包括末尾追加的\0。如果发生了截断，则代表在不限制打印字符个数的情况下可以写入的字符个数，不包括末尾追加的\0。如果格式化解析失败，则返回负数。

### `setvbuf()` 缓冲设置
定义流 stream 应如何缓冲。
```c
int setvbuf(FILE *stream, char *buffer, int mode, size_t size)
```

- **stream** -- 这是指向 FILE 对象的指针，该 FILE 对象标识了一个打开的流。
- **buffer** -- 这是分配给用户的缓冲。如果设置为 NULL，该函数会自动分配一个指定大小的缓冲。
- **mode** -- 这指定了文件缓冲的模式：

|模式|描述|
|---|---|
|_IOFBF|**全缓冲**：对于输出，数据在缓冲填满时被一次性写入。对于输入，缓冲会在请求输入且缓冲为空时被填充。|
|_IOLBF|**行缓冲**：对于输出，数据在遇到换行符或者在缓冲填满时被写入，具体视情况而定。对于输入，缓冲会在请求输入且缓冲为空时被填充，直到遇到下一个换行符。|
|_IONBF|**无缓冲**：不使用缓冲。每个 I/O 操作都被即时写入。buffer 和 size 参数被忽略。|

- **size** --这是缓冲的大小，以字节为单位。

返回值：
如果成功，则该函数返回 0，否则返回非零值。

使用场景：
```text
// 无缓冲 - 立即输出，性能最低但实时性最强
setvbuf(fp, NULL, _IONBF, 0);
// 使用场景：错误日志、调试输出、需要立即看到结果的情况

// 行缓冲 - 遇到换行符或缓冲区满时输出  
setvbuf(fp, NULL, _IOLBF, BUFSIZ); // 默认通常是4096
// 使用场景：终端输出、交互式程序、日志系统（推荐！）

// 全缓冲 - 缓冲区满时才输出，性能最高
setvbuf(fp, NULL, _IOFBF, 8192); // 可以设置更大的缓冲区
// 使用场景：大文件读写、批量数据处理、网络传输
```
## `<string.h>`
### `strstr()`
用于在字符串 haystack 中查找子字符串 needle 的第一次出现位置。如果找到，则返回指向该位置的指针；如果未找到，则返回 NULL。
```c
char *strstr(const char *haystack, const char *needle);
```
- **haystack** -- 要搜索的主字符串。
- **needle** -- 要查找的子字符串。
### `memset`()
用于将一段内存区域设置为指定的值。

`memset()` 函数将指定的值 c 复制到 str 所指向的内存区域的前 n 个字节中，这可以用于将内存块清零或设置为特定值。

在一些情况下，需要快速初始化大块内存为零或者特定值，memset() 可以提供高效的实现。

在清空内存区域或者为内存区域赋值时，memset() 是一个常用的工具函数。

```c
void *memset(void *str, int c, size_t n)

- str -- 指向要填充的内存区域的指针。
- c -- 要设置的值，通常是一个无符号字符。
- n -- 要被设置为该值的字节数。
```
该值返回一个指向存储区 str 的指针。

- `memset()` 并不对指针 `ptr` 指向的内存区域做边界检查，因此使用时需要确保 `ptr` 指向的内存区域足够大，避免发生越界访问。
- `memset()` 的第二个参数 `value` 通常是一个 `int` 类型的值，但实际上只使用了该值的低8位。这意味着在范围 `0` 到 `255` 之外的其他值可能会产生未定义的行为。
- `num` 参数表示要设置的字节数，通常是通过 `sizeof()` 或其他手段计算得到的。
### `strncmp()`
**`strncmp()`** 是一个标准库函数，用于比较两个字符串的前 **n** 个字符是否相等。
通常用于比较两个字符串，以确定它们是否相等或哪个字符串在字典顺序上更小。
```c
int strncmp(const char *str1, const char *str2, size_t n)
```
- **str1** -- 要进行比较的第一个字符串。
- **str2** -- 要进行比较的第二个字符串。
- **n** -- 要比较的最大字符数。

该函数返回值如下：
- 如果返回值 < 0，则表示 str1 小于 str2。
- 如果返回值 > 0，则表示 str1 大于 str2。
- 如果返回值 = 0，则表示 str1 等于 str2。

与`strcmp`区别
1. 比较范围：strcmp比较到'\0'结束，strncmp最多比较n个字符
2. 安全性：strncmp更安全，可以防止缓冲区溢出
3. 性能：strncmp可能更快（当n较小时）
主要区别在于比较的长度控制。strcmp比较整个字符串直到遇到'\0'，而strncmp可以指定最大比较长度n，这在处理不可信输入时特别重要，能防止缓冲区溢出。不过要注意strncmp的n参数如果超过实际字符串长度，可能得到意外的比较结果。


### `strdup()`
用于**复制字符串**,
1. 动态分配足够的内存来存储原字符串
    
2. 将原字符串（包括终止空字符 `\0`）复制到新分配的内存中
    
3. 返回指向新字符串的指针

```c
char *strdup(const char *str);

```
- **成功**：返回指向新分配的字符串的指针
    
- **失败**：返回 `NULL`（通常是内存分配失败）
`strdup` 使用 `malloc` 分配内存，调用者必须使用 `free` 释放内存


### `strncpy()`
把 **src** 所指向的字符串复制到 **dest**，最多复制 **n** 个字符。当 src 的长度小于 n 时，dest 的剩余部分将用空字节填充。
```c
char *strncpy(char *dest, const char *src, size_t n)
```
- **dest** -- 指向用于存储复制内容的目标数组。
- **src** -- 要复制的字符串。
- **n** -- 要从源中复制的字符数。

返回值
该函数返回最终复制的字符串。


### strcpy

```c
char *strcpy(char *dest, const char *src)
```
把 **src** 所指向的字符串复制到 **dest**。
需要注意的是如果目标数组 dest 不够大，而源字符串的长度又太长，可能会造成缓冲溢出的情况。
### `memcpy()`
从存储区 **str2** 复制 **n** 个字节到存储区 **str1**。
```c
void *memcpy(void *str1, const void *str2, size_t n)
```
- **str1** -- 指向用于存储复制内容的目标数组，类型强制转换为 void* 指针。
- **str2** -- 指向要复制的数据源，类型强制转换为 void* 指针。
- **n** -- 要被复制的字节数。

返回值
该函数返回一个指向目标存储区 str1 的指针。

## `<sys/ioctl.h>
```c
int ioctl(int fd, unsigned long request, ...);
```
一个**可变参数**的系统调用，用于设备特定的控制操作。
fd必须是是有效的、已打开的设备文件描述符

request，请求码
```text
// 32位request的组成
| 31-30 | 29-16 | 15-8  | 7-0   |
|-------+-------+-------+-------|
| dir   | size  | type  | nr    |
   2    |   14  |   8   |   8
// 实际使用宏来构造
_IOC(dir, type, nr, size)
```
常用宏定义
```c
_IO(type, nr)            // 无参数
_IOR(type, nr, size)     // 读（从驱动到用户）
_IOW(type, nr, size)     // 写（从用户到驱动）
_IOWR(type, nr, size)    // 双向传输
```
- **dir**（方向）：`_IOC_NONE`(0)、`_IOC_READ`(2)、`_IOC_WRITE`(4)
- **type**（类型）：8位幻数，避免冲突（如 'k' 表示键盘）
- **nr**（序号）：8位命令编号
- **size**：传输的数据大小
... 可变参数，常用指针

成功：返回0或非负值（取决于实现）
失败：返回-1，并设置errno
errno：
- `EINVAL`：无效的request或参数
- `EFAULT`：用户空间指针无效
- `ENOTTY`：fd不是字符设备
- `EACCES`：权限不足




## <stdlib.h>

### qsort()

`qsort` 是 C 标准库中提供的一个函数，用于对数组进行快速排序。它在 `<stdlib.h>` 头文件中定义。`qsort` 使用的是快速排序算法（quicksort），这是一种高效的排序算法，平均时间复杂度为 O(n log n)。
```c
void qsort(void *base, size_t nitems, size_t size, int (*compar)(const void *, const void *));
```

### free()
用于释放由 `malloc()`, `calloc()`, `realloc()` 等动态分配函数分配的内存。当动态分配的内存不再需要时，调用 `free()` 函数可以避免内存泄漏，确保程序有效地管理内存。

```c
void free(void *ptr)
```
- **释放正确的内存**：只能释放通过动态内存分配函数分配的内存，不能释放由其他方式分配的内存（例如局部变量或全局变量）。
    
- **避免重复释放**：同一个内存块不能多次释放，否则可能导致未定义行为。
    
- **释放后指针处理**：释放内存后，指针仍然指向已释放的内存位置。为了避免悬空指针，可以将指针设为 `NULL`。
- **检查空指针**：调用 `free()` 前最好检查指针是否为空，以确保程序稳定性。

- **内存泄漏**：如果动态分配的内存没有被释放或丢失了对其的引用，内存将无法再被程序使用，造成内存泄漏。
- **悬空指针**：指向已释放内存的指针称为悬空指针。如果悬空指针被再次访问，会导致未定义行为，可能引起程序崩溃或数据损坏。

在 C 语言中，调用 free() 释放动态分配的内存后，该指针仍然保存着之前分配的地址，这会导致悬空指针（dangling pointer）。悬空指针是指向已释放内存的指针，如果对其进行解引用操作，会导致未定义行为。

为了避免悬空指针问题，通常的做法是在调用 free() 之后，将指针设置为 NULL。这样可以确保程序不会误使用已释放的内存。

### dup()
复制一个已打开的文件描述符 `oldfd`
给当前打开文件再分配一个最小 fd，常用来备份 stdout、做简易重定向，原子性由后续 close+dup 两步完成。
```c
#include <unistd.h>
int dup(int oldfd);           // 复制 fd，返回“最小可用”新描述符

```
dup返回当前进程里**最小可用**的 fd，让它指向**跟 oldfd 完全相同的打开文件表项**。
注意dup产生的新fd会继承oldfd的偏移量，两者的偏移量是共享的，会导致先写：`write(oldfd)` 再写： `write(newfd)` 会**连续写**。


常用于：
1.保存原stdout,备份标准输出，后续可恢复`int saved = dup(STDOUT_FILENO);`
2.实现简单重定向，`dup(fd); close(STDOUT_FILENO);`
3.父子进程共享资源，`fork()` 前 dup，子进程继承同一偏移
```c
/* 把标准输出重定向到文件 log.txt */
int fd = open("log.txt", O_WRONLY|O_CREAT|O_TRUNC, 0644);
if (fd < 0) exit(1);

int new_stdout = dup(fd);      // 备份原 stdout（如需恢复）
dup2(fd, STDOUT_FILENO);       // 原子替换：stdout → log.txt
close(fd);                     // fd 已复制，可关闭

printf("now write into file\n");   // 实际写到 log.txt

dup2(new_stdout, STDOUT_FILENO);   // 恢复 stdout
close(new_stdout);
printf("back to terminal\n");
```
fcntl 可指定最小号下限，dup 总是从 0 开始找；fcntl 还能带 CLOEXEC。


dup 返回最小未用描述符；dup2 复制到指定 fd，若已打开则先关闭，原子完成。
dup2 原子替换指定 fd，避免竞态；dup 还要 close+dup 两步，不原子。


### dup2()
dup2 先关 `newfd`（若已打开），再让 `newfd` 指向 `oldfd` 的文件表，**整个动作原子**，返回值就是 `newfd`。
```c
int dup2(int oldfd, int newfd); // 复制到指定 newfd；若 newfd 已打开则先关闭
```
作用就是把 `oldfd` 复制到**指定的** `newfd` 编号
而且复制和替换**在一次系统调用完成**，不会出现“旧` fd` 已关、新 `fd` 还没建好”的中间态。

返回值：
成功 → **newfd 本身**；失败 → -1，设置errno = EBADF/EMFILE

错误码`EBADF`是指oldfd 或 `newfd` 无效
而`EMFILE`是进程` fd` 表已满
```c
	 int saved_stdout = dup(STDOUT_FILENO);      // 备份 stdout
    int fd = open("log.txt", O_WRONLY|O_CREAT|O_TRUNC, 0644);
    if (fd < 0) { perror("open"); return 1; }

    if (dup2(fd, STDOUT_FILENO) < 0) {          // 原子重定向
        perror("dup2"); return 1;
    }
    close(fd);                                  // 关闭多余副本

    printf("写入 log.txt\n");            // 实际写文件

    fflush(stdout);
    dup2(saved_stdout, STDOUT_FILENO);          // 恢复 stdout
    close(saved_stdout);
    printf("已回到终端\n");

```

## `fcntl`
### `fcntl`()
File Control（文件控制）
**对已打开的文件描述符进行各种控制操作**（复制、状态、锁、信号等）
常用于复制描述符、改变打开标志、设置异步通知
```c
#include <unistd.h>
#include <fcntl.h>

int fcntl(int fd, int cmd, ... /* arg */ );
```
可变参数取决于cmd
- **`F_GETFL`**：获取文件状态标志
- **`F_SETFL`**：设置文件状态标志
- **`F_GETFD`**：获取文件描述符标志
- **`F_SETFD`**：设置文件描述符标志

| cmd               | 第 3 参       | 功能                                   | 面试高频                  |               |         |
| :---------------- | :---------- | :----------------------------------- | :-------------------- | ------------- | ------- |
| `F_DUPFD`         | `int newfd` | 复制 fd，**返回 ≥ newfd 的最小未用描述符**        | 重定向基础                 |               |         |
| `F_DUPFD_CLOEXEC` | `int newfd` | 同上且自动置 `O_CLOEXEC`                   | 线程/守护进程               |               |         |
| `F_GETFL`         | 无           | 取当前 **open 标志**（`O_RDONLY`           | O_NONBLOCK`...）判断阻塞模式 |               |         |
| `F_SETFL`         | `int flags` | 设置 **open 标志**（仅 `O_APPEND`          | O_NONBLOCK            | O_ASYNC` 等可改） | 设非阻塞、追加 |
| `F_SETOWN`        | `int pid`   | 把 fd 的 **SIGIO/SIGURG 接收者**设为指定进程/线程 | 异步通知                  |               |         |
| `F_GETOWN`        | 无           | 读取当前 SIGIO 接收者                       | 配合上面使用                |               |         |
返回值：
成功，**新 fd（dup 类）** 或 **标志值（get 类）**
失败返回-1，设置errno为如 `EINVAL`（cmd 非法）、`EBADF`（fd 无效）

```c
int set_nonblock(int fd)
{
    int fl = fcntl(fd, F_GETFL, 0);
    if (fl == -1) return -1;
    return fcntl(fd, F_SETFL, fl | O_NONBLOCK);   // 设非阻塞
}

int dup_cloexec(int oldfd)
{
    return fcntl(oldfd, F_DUPFD_CLOEXEC, 0);      // 复制且自动关闭-on-exec
}
```

**fcntl 不能改 open 时的所有标志，只能改 `O_APPEND、O_NONBLOCK、O_ASYNC、O_DIRECT` 等少数状态位，创建标志（O_CREAT / O_TRUNC）改不了。**
`F_DUPFD` 可指定‘大于等于 `newfd `的最小未用描述符’；dup2 则是固定目标 fd，且没有 `CLOEXEC` 版本。
设置fd为非阻塞的形式：
`fcntl(fd, F_SETFL, fcntl(fd,F_GETFL) | O_NONBLOCK)`



### `open()`
open()是Linux最基础的文件操作系统调用，通过位掩码flags控制打开方式。最需要注意的是O_CREAT时需提供mode参数，但实际权限受umask影响。open()的原子操作特性（如O_EXCL、O_APPEND）在并发编程中非常重要，能避免竞态条件。

```c
#include <sys/types.h> // 基本系统数据类型
#include <sys/stat.h> // mode_t类型和权限常量
#include <fcntl.h> // open()函数原型和标志定义

int open(const char *pathname, int flags);
int open(const char *pathname, int flags, mode_t mode);仅当创建新文件可改权限，即mode仅在指定O_CREAT创建新文件时生效
```
pathname可以是绝对路径或相对路径，也可以是普通文件、设备文件、目录等

flags
访问模式： （互斥，只能三选一）
```c
O_RDONLY    // 只读     (00)
O_WRONLY    // 只写     (01)
O_RDWR      // 读写     (02)
```
**创建和行为标志**（可组合）:
```c
// 文件创建
O_CREAT     // 文件不存在则创建
O_EXCL      // 与O_CREAT一起使用，文件必须不存在
O_TRUNC     // 打开时清空文件
O_APPEND    // 追加模式（原子操作）

// 文件状态
O_ASYNC     // 启用信号驱动I/O
O_DIRECT    // 直接I/O（绕过缓存）
O_NOFOLLOW  // 不解析符号链接
O_NONBLOCK  // 非阻塞模式
O_SYNC      // 同步写入（数据+元数据落盘）

// 错误处理  
O_CLOEXEC   // 执行exec时关闭（原子操作）
O_TMPFILE   // 创建匿名临时文件
```

mode:通常用八进制表示
```c
S_IRUSR  (0400)  // 用户读
S_IWUSR  (0200)  // 用户写  
S_IXUSR  (0100)  // 用户执行
S_IRGRP  (0040)  // 组读
S_IWGRP  (0020)  // 组写
S_IXGRP  (0010)  // 组执行
S_IROTH  (0004)  // 其他读
S_IWOTH  (0002)  // 其他写
S_IXOTH  (0001)  // 其他执行

// 常用组合（八进制表示更直观）
0644  // rw-r--r--  普通文件
0755  // rwxr-xr-x  可执行文件
0600  // rw-------  配置文件
```
实际权限：
```c
// 实际权限 = mode & ~umask
// 例如：
umask(022);             // 设置umask
open("file", O_CREAT, 0666);  // 请求rw-rw-rw-
// 实际得到：rw-r--r-- (0644)
```
umask是用户掩码，决定"禁止哪些权限"，是一种安全机制，用于限制新建文件的默认权限。
- **成功**：返回文件描述符（非负整数）
    
- **失败**：返回-1，设置errno


常见errno
```c
ENOENT    // 文件不存在（且未指定O_CREAT）
EACCES    // 权限不足  
EEXIST    // 文件已存在（O_CREAT | O_EXCL）
EISDIR    // 路径是目录
EMFILE    // 进程打开文件数达到上限
ENOSPC    // 磁盘空间不足
```

注意原子操作：
```c
// ❌ 非原子操作（竞态条件）
if (!access("file", F_OK)) {
    fd = open("file", O_RDWR);  // 可能在这之间文件被删除
}

// ✅ 原子操作
fd = open("file", O_RDWR | O_CREAT | O_EXCL, 0644);
// 要么创建新文件，要么文件存在时失败
```
O_APPEND
```c
fd = open("log.txt", O_WRONLY | O_APPEND);
// 多个进程同时写入不会相互覆盖
// 每次write前，文件偏移自动移到末尾
```

- **timer** -- 这是指向表示日历时间的 `time_t` 值的指针。


### `strftime()`
根据给定的格式字符串，将一个 `struct tm` 结构表示的时间格式化为一个字符串。

```c
size_t strftime(char *str, size_t maxsize, const char *format, const struct tm *timeptr)
```
- `str`：指向目标字符数组的指针，用于存放生成的字符串。
    
- `maxsize`：目标数组的最大容量，防止缓冲区溢出。
    
- `format`：格式控制字符串，类似于 `printf` 的格式（如 `"%Y-%m-%d %H:%M:%S"`）。
    
- `timeptr`：指向 `struct tm` 结构的指针。


- - 成功：返回写入的字符数（不包括终止空字符）。
        
    - 如果字符数（含空字符）超过 `maxsize`，则返回 `0`，此时数组内容是不确定的。
允许自定义任何时间输出格式。

```c
 time_t now = time(NULL);
 struct tm *tm_info = localtime(&now);
 char time_buf[64];
 strftime(time_buf, sizeof(time_buf), "%Y-%m-%d %H:%M:%S", tm_info);
```
