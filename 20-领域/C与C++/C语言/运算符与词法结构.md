# 标识符
# 标识符
可以用存储期描述对象（存有数据的硬件内存，可存储一个或多个值），指对象在内存中保留了多长时间。
可以用作用域和连接描述标识符，它们表明了哪些程序的哪些部分可以使用它。

## 三套属性：作用域 / 链接属性 / 存储期

上面那句话是 C 语言标识符体系的总纲。一个标识符有三套互相独立的属性，
**`static` 和 `extern` 的行为必须用这三套属性一起解释才完整**：

| 属性 | 回答的问题 | 取值 |
|---|---|---|
| **作用域**（scope） | 这段代码里**能不能看见**这个名字 | 文件 / 函数 / 块 / 函数原型 |
| **链接属性**（linkage） | 这个名字在不同文件/多次声明里，**是不是同一个实体** | 外部链接 / 内部链接 / 无链接 |
| **存储期**（storage duration） | 这个对象的内存**活多久** | 静态 / 线程 / 自动 / 动态分配 |

### 作用域：名字在哪可见

| 作用域 | 范围 | 例子 |
|---|---|---|
| **文件作用域** | 声明在所有函数之外，从声明处到文件末尾 | 全局变量、全局函数 |
| **函数作用域** | 整个函数体内有效（只用于 `goto` 标签） | `goto err:` 的 `err` |
| **块作用域** | `{}` 内部，从声明到块结束 | 局部变量、形参 |
| **函数原型作用域** | 只在原型声明里有效 | `int f(int size);` 的 `size` |

### 链接属性：重名是不是同一个东西

| 链接属性 | 含义 | 谁是 |
|---|---|---|
| **外部链接**（external） | 多个文件（或同文件多次声明）里的这个名字指**同一个**实体 | 全局变量、普通函数 |
| **内部链接**（internal） | 只属于**本文件**——加了 `static` 的全局 | `static int count;` |
| **无链接**（none） | 各自独立，重名互不相干 | 局部变量、形参 |

**`static` 的第二种身份就在这里**：修饰全局变量/函数时，它把链接属性从外部改成内部——
别的文件即使 `extern` 也看不到。这就是"信息隐藏"，C 语言版本的"私有"。

### 存储期：内存活多久

| 存储期 | 谁适用 | 生命周期 |
|---|---|---|
| **静态** | 全局变量、`static` 变量 | 程序开始到结束（数据区/静态区） |
| **自动** | 块内局部变量（默认） | 进块创建、出块销毁（栈区） |
| **动态分配** | `malloc/free` 管的 | 手动控制（堆区） |
| **线程**（C11 `_Thread_local`） | 每线程一份 | 线程生命周期 |

### 三者的关系：一张矩阵看懂 static/extern

| 声明 | 作用域 | 链接属性 | 存储期 |
|---|---|---|---|
| `int a;`（函数外） | 文件 | 外部 | 静态 |
| `static int a;`（函数外） | 文件 | **内部** | 静态 |
| `extern int a;`（文件外引用） | 文件 | 外部（指向别处定义） | 静态 |
| `int a;`（块内） | 块 | 无 | 自动 |
| `static int a;`（块内） | 块 | 无 | **静态**（改变的是存储期！） |
| `extern int a;`（块内引用） | 块 | 外部 | 静态 |
| `register/auto int a;`（块内） | 块 | 无 | 自动 |

**两个最容易混的点**：

1. **`static` 在块内和文件外作用完全不同**：
   - 文件外：改**链接属性**（外部→内部），作用域不变、存储期不变；
   - 块内：改**存储期**（自动→静态），作用域不变、链接属性不变。
   ——同一个关键字干两件不同的事，这就是为什么必须用三套属性来解释。
2. **头文件里为什么不能定义全局变量**：`int a;` 放头文件被多个 `.c` include 后，
   每个文件都有一份"外部链接的 `a`"，链接器报重复定义。
   正确做法：头文件里 `extern int a;` 声明，某个 `.c` 里定义。

> 依据：C11 标准 6.2.1（标识符作用域）、6.2.2（链接属性）、6.2.4（存储期）；
> 与《C Primer Plus》第 12 章"存储类别、链接和内存管理"同源。
> 运算符部分（见下）依据 C11 6.5 与 K&R。

## 位运算符
位运算无借位，无进位，不受相邻比特位的影响，这是与传统运算的根本区别
### 与&
位与运算(&)：有0为0，双1为1
	·a&1判断奇偶（a%2)

a=a%8;  可以改为：  a=a&7;
### 或|
**有1为1，双0为0**


### 取反~
各位取反：0变1,1变0


### 异或^
不同为1，相同为0
任何数和 0 做异或运算，结果仍然是原来的数，即 `a⊕0=a`。
任何数和其自身做异或运算，结果是 0，即 `a⊕a=0。`
异或运算满足交换律和结合律，即 `a⊕b⊕a=b⊕a⊕a=b⊕(a⊕a)=b⊕0=b。`
**交换两数**：
1.借助临时变量
2.
```c
a = a + b; 
b = a - b; 
a = a - b;
```
3.
```c
a ^= b; 
b ^= a; 
a ^= b;
```
### 左移<<
所有位依次向左移动，高位丢弃，低位补0。
左移常被用来做 某数* (2 ^ n)的运算，因为直接基于二进制运算，所以左移效率比 * (2 ^ n)高。

### 右移>>
无符号右移`>>>`，**无符号数据**：所有位依次向右移动，高位补0，低位丢弃。
**有符号数据**：所有位依次向右移动，符号位不变，低位丢弃。
右移常被用来做某数 / (2 ^ n)的运算，因为直接基于二进制运算，所以右移效率比 / (2 ^ n)高。

## 逗号运算符
逗号运算符允许在单个表达式中按顺序执行多个子表达式，并以最后一个子表达式的值作为整个表达式的结果。  
逗号运算符在某些特定场景下非常实用，比如初始化多个变量或在循环中执行多步操作。


逗号运算符的关键特性：
- 顺序执行：所有子表达式按顺序求值，保证左侧先于右侧执行。
- 返回值：整个表达式的值是最后一个子表达式的值，前面的子表达式仅执行但不影响结果。

逗号运算符的优先级在 C语言中是最低的，甚至低于赋值运算符 `=`。这意味着在复杂表达式中，必须用括号明确它的范围，否则可能导致误解。
