# RTOS 导览

> 一句话：这一片回答「单片机怎么同时跑多个任务、彼此怎么通信、又怎么保证实时」。

## 装什么 / 不装什么

- **装**：脱离具体芯片也能成立的实时内核知识——任务、调度、同步与通信、时间、内存、中断边界。
- **不装**：具体板子的接线上电日志、某次烧录失败过程 → 那些在 `10-项目/FRDM-IMX95-PRO/`。
- **不装**：ARM Cortex-M 内核本身（NVIC、SysTick 寄存器细节）→ 在 `20-领域/嵌入式通用/ARM架构`。

## 建议阅读顺序

1. 先看 [[20-领域/RTOS/FreeRTOS.md|FreeRTOS]] —— 它以 FreeRTOS 为主线，把任务/调度/队列/信号量/中断串起来，**这是主干**。
2. 再看 [[20-领域/RTOS/uC-OS-II.md|uC/OS-II]] —— 拿它和 FreeRTOS 对照，尤其「任务状态机」「内核 API」两套命名，能帮你理解"RTOS 都长一个样"。
3. 两者都过一遍后，回到主干里"八、RTOS 横向对比"一节收尾。
