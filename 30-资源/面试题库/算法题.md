### 给定数组和一个整数k，问有多少长度至少为2且元素和为k的倍数的子数组
<[523. 连续的子数组和](https://leetcode.cn/problems/continuous-subarray-sum/)>
<[974. 和可被 K 整除的子数组](https://leetcode.cn/problems/subarray-sums-divisible-by-k/)>
**前缀和**：把数组从开头到每个位置的和预先计算并存储起来,可以**快速计算任意子数组的和**
`prefix[i] = nums[0] + nums[1] + ... + nums[i]`
**同余定理**：如果两个数 `a` 和 `b` 除以 `k` 的余数相同，那么 `a - b` 是 `k` 的倍数。

`子数组[i,j]的和 = prefix[j] - prefix[i-1]`
推论：`prefix[j] - prefix[i-1] 是 k 的倍数⇔ prefix[j] % k == prefix[i-1] % k`
"前缀和+同余定理"的思路在很多子数组问题中都有应用

```c
int subarraysDivByK(int* nums, int numsSize, int k) {
    int count = 0;
    int prefixSum = 0;
    
    int* modCount = (int*)calloc(k, sizeof(int));
    modCount[0] = 1;  // 为了处理从数组开头开始的子数组。
    
    for (int i = 0; i < numsSize; i++) {
        prefixSum += nums[i];
        int mod = prefixSum % k;
        //在C语言中，负数的取模运算结果可能是负数
        if (mod < 0) mod += k;
        
		      // modCount[mod]表示在i之前有多少个位置的前缀和余数也是mod
//直接加modCount[mod]相当于组合数，因为每出现一个新的，就可以和前面n个组成n个符合条件的子数组
        count += modCount[mod];
        modCount[mod]++;
    }
    
    free(modCount);
    return count;
}
```

## [4. 寻找两个正序数组的中位数](https://leetcode.cn/problems/median-of-two-sorted-arrays/)

```c
double findMedianSortedArrays(int* nums1, int nums1Size, int* nums2, int nums2Size) {

    if (nums1Size > nums2Size) {

        // 利用递归交换 nums1 和 nums2

        return findMedianSortedArrays(nums2, nums2Size, nums1, nums1Size);

    }

  

    // 循环不变量：a[left] <= nums2[j+1]

    // 循环不变量：a[right] > nums2[j+1]

    int left = -1, right = nums1Size;

    while (left + 1 < right) { // 开区间 (left, right) 不为空

        int i = left + (right - left) / 2;

        int j = (nums1Size + nums2Size + 1) / 2 - i - 2;

        if (nums1[i] <= nums2[j + 1]) {

            left = i; // 缩小二分区间为 (i, right)

        } else {

            right = i; // 缩小二分区间为 (left, i)

        }

    }

  

    // 此时 left 等于 right-1

    // nums1[left] <= nums2[j+1] 且 nums1[right] > nums2[j'+1] = nums2[j]，所以答案是 i=left

    int i = left;

    int j = (nums1Size + nums2Size + 1) / 2 - i - 2;

    int ai = i >= 0 ? nums1[i] : INT_MIN;

    int bj = j >= 0 ? nums2[j] : INT_MIN;

    int ai1 = i + 1 < nums1Size ? nums1[i + 1] : INT_MAX;

    int bj1 = j + 1 < nums2Size ? nums2[j + 1] : INT_MAX;

    int max1 = MAX(ai, bj);

    int min2 = MIN(ai1, bj1);

    return (nums1Size + nums2Size) % 2 ? max1 : (max1 + min2) / 2.0;

}
```
- **nums1的左半部分**：`(-1, i]` 共 i+1 个元素
    
- **nums2的左半部分**：`(-1, j]` 共 j+1 个元素
    
- **总左半部分**：`(i+1) + (j+1) = (m+n+1)/2` 个元素
m+n是偶数，每组大小都是(m+n)/2,m+n是奇数，让左半组多1个，大小是(m+n+1)/2
合并之后就是$\lfloor (m+n+1)/2 \rfloor$`
`nums1[i]     : 第一个数组左半部分的最大值
`nums2[j]     : 第二个数组左半部分的最大值
`nums1[i+1]   : 第一个数组右半部分的最小值  
`nums2[j+1]   : 第二个数组右半部分的最小值
需满足下面条件，但是由于两数组都是升序且i和j是类似互补的关系，所以只需判断一个就可以了
1. `nums1[i] <= nums2[j+1]` // 第一个数组左半部分 ≤ 第二个数组右半部分
    
2. `nums2[j] <= nums1[i+1]` // 第二个数组左半部分 ≤ 第一个数组右半部分





## **求一个整数存储在内存中的二进制里1的个数**

```c
# include <stdio.h>

循环移位

int count_bits_method1(int num) {

    int count = 0;

    int bits = sizeof(num) * 8;  // 整数的总位数

    for (int i = 0; i < bits; i++) {

        if (num & 1) {  // 检查最低位是否为1         未考虑负整数，且低效

            count++;

        }

        num >>= 1;  // 右移一位

    }

    return count;

}

高效：位运算符

int count_bits_method3(int num) {

    int count = 0;

    unsigned int unum = (unsigned int)num;

    while (unum) {

        count++;

        unum = unum & (unum - 1);  // 每次消除最低位的1

    }

    return count;

}
```
