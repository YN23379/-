### 知识点


#### 微机原理
CPU：内部有运算器，控制器（核心是程序计数器）和寄存器（高速存储单元）
- CPU通过 **CS:IP** 寄存器拿到下一条指令的地址。
- 通过**地址总线**将该地址送到内存。
- 通过**数据总线**从该地址读取指令操作码，并存入CPU内部的**指令寄存器**。
- **控制器**分析指令，指挥**运算器**执行。
- **IP**寄存器自动增加，指向下一条指令。
- 循环往复。

1. 计算机遵循**冯·诺依曼**“存储程序”结构。
2. CPU通过 **CS:IP** 寄存器取指，通过**三大总线**与内存/外设交互。
3. **地址总线**宽度决定**决定了计算机系统最大能支持多少物理内存。数据总线**宽度决定**决定了计算机系统在单位时间内的数据处理能力**，通常就是CPU的位数
4. 访问外设有**内存映射**和**独立编址**两种方式。
5. **中断**是处理异步事件、提高效率的关键机制。

UART
- **波特率**：单位时间内传输的**符号个数**。
    
- **比特率**：单位时间内传输的**二进制位数**。
    
- 在UART中，一个符号代表一个比特，所以两者数值相等。

SPI：由**时钟极性(CPOL)** 和**时钟相位(CPHA)** 决定，共4种模式(0,1,2,3)。主要区别在于**时钟空闲时的电平**和**数据在哪个时钟沿被采样**。
I2C：**如何解决总线冲突？， 通过**“线与” 逻辑和**仲裁机制**。需要上拉电阻：接口是**开源输出**，只能拉低电平，不能主动拉高，需要上拉电阻将总线置于高电平，代表逻辑‘1’。
CAN：**抗干扰能力强**：使用**差分信号**。干扰信号会同时作用于CAN_H和CAN_L，接收端检测的是两者的电压差，共模干扰被抵消。

- **RAM（随机存取存储器）**：**临时记忆**，速度快，**断电后数据丢失**（易失性）。用于**临时存放**正在运行的程序和数据。
- **ROM（只读存储器）**：**永久记忆**，速度慢，**断电后数据不丢失**（非易失性）。用于**永久存放**固件、启动代码等。
进程与线程：
[[多线程编程#进程与线程：]]
**进程是资源分配的基本单位**，每个进程有独立的地址空间（代码、数据、堆栈），互不干扰。**线程是CPU调度的基本单位**，它是进程内部的一个执行流，**多个线程共享同一进程的地址空间和资源**（如打开的文件、全局变量）。
进程间通信（IPC）：管道是最基本的IPC，共享内存是最快的IPC，信号（异步机制），套接字的功能最强大，可用于网络通信，还有消息队列（内核的一个链表）。

3. **控制逻辑简单**：直接用MCU的GPIO口就可以方便地控制MOS管的通断，简化了驱动电路的设计。”

5. **参数测量**：然后，我会重点测量两个关键参数：
    
    - **频率**：确认是否符合电机驱动的需求。
        
    - **占空比**：通过示波器的自动测量功能，验证当我在代码中改变占空比设置时，示波器上读到的数值是否同步、线性地变化。
        
6. **动态调试**：最后，将PWM信号实际输入到电机驱动电路，同时用示波器监测。我会观察在电机启动、加速、刹车等负载变化的瞬间，PWM信号的波形是否会出现畸变或抖动，以确保驱动电路的稳定性。”

#### 头文件内容
头文件只声明不做定义，除非这个声明的结构需要被其他源文件使用（也就是需要前向声明和公共访问），否则就在该头文件对应的源文件里作具体的定义，隐藏结构
在C语言中这是为了保证，**同一个符号（变量、函数、类型）在整个程序中只能有一个定义**。
前向声明：让其他文件知道有这个类型，但**不能创建实例或访问成员**，只能通过提供的API函数操作。在头文件声明类型，但定义只在对应的源文件内完成
如果是前向声明，那就不可以声明这个类型的变量也不能访问成员
```c
//  前向声明：只告诉编译器"存在这个类型"
typedef struct threadpool threadpool_t;
// 编译器知道：有个叫 threadpool_t 的类型
// 但不知道它有多大，有哪些成员

// 使用场景：
void process_pool(threadpool_t *pool);  // 可以声明指针参数
threadpool_t* create_pool(void);        // 可以声明返回指针的函数

// ❌ 不能做的：
// sizeof(threadpool_t)                 // 错误：不知道大小
// threadpool_t pool;                   // 错误：不能定义实例
// pool->queue_size = 10;               // 错误：不能访问成员
```
公共访问：让其他文件可以访问结构体的成员
即其他源文件就可以声明这个类型的变量，并且可以访问变量的成员
```text
是否需要外部直接访问成员？
    ├─ 否 → 使用不透明指针（typedef struct X X_t;）
    │     ├─ 优点：封装好，安全性高
    │     └─ 缺点：需要getter/setter函数
    │
    └─ 是 → 
          ├─ 需要高性能访问 → 透明结构（在头文件定义）
          │     ├─ 优点：直接访问，可能内联优化
          │     └─ 缺点：暴露实现细节
          │
          └─ 只需要部分访问 → 混合模式
                ├─ 头文件：公开需要访问的成员
                └─ 源文件：私有成员的定义
```

```c
// ✅ 方法1：完整定义在头文件（透明结构）
// threadpool.h
typedef struct threadpool {
    int thread_count;      // 公共可访问
    int queue_size;        // 公共可访问
    // 可能还有其他私有成员
    void *private_data;    // 隐藏实现细节
} threadpool_t;

// 使用：
threadpool_t pool;
pool.thread_count = 10;    // ✅ 可以直接访问


// ✅ 方法2：提供getter/setter函数（更推荐）
// threadpool.h
typedef struct threadpool threadpool_t;  // 不透明指针

// 访问函数
int threadpool_get_thread_count(threadpool_t *pool);
int threadpool_get_queue_size(threadpool_t *pool);

// threadpool.c
struct threadpool {
    int thread_count;      // 私有，外部不可直接访问
    int queue_size;        // 私有
    pthread_mutex_t lock;  // 实现细节
};

int threadpool_get_thread_count(threadpool_t *pool) {
    return pool->thread_count;  // 内部可以访问
}
```

|可以放在头文件|不应该放在头文件|
|---|---|
|函数声明（extern）|函数定义|
|类型声明（typedef）|变量定义|
|宏定义|结构体/联合体定义（除非需要内联）|
|枚举声明|静态函数|
|常量声明|全局变量定义|

### 运行elf和环境变量

我注意到自己编译的ELF文件需要`./`或绝对路径才能运行，而系统命令可以直接使用。对这个疑问研究后我发现，这主要是因为`PATH`环境变量的作用——因为shell会在`PATH`列出的目录中查找可执行文件。要让自定义程序也能这样，可以把它放到`PATH`中的目录，或者把自己的目录加到`PATH`里。
而且像`cd`这种命令必须是shell内置的，因为如果是外部程序，它只能改变子进程的目录，无法影响当前shell的环境。
[[Linux基础与开发环境#常见环境变量]]

我自己编写的项目程序生成最终的elf可执行文件之后，运行的话需要在终端上输入文件名而且在前面加上路径，一般就是./开头的相对路径或者是根目录开头的绝对路径。而我正常使用基础命令和其他工具的时候就有疑问，这些命令应该也是elf文件，为什么可以在大多数场景里直接输入指令名称就能调用？
我就去用file看了下/bin文件里的指令也确实是elf文件，能实现直接运行的功能是因为环境变量`PATH`,它告诉shell在哪些目录里查找可执行文件，可以用`echo $PATH`直接查看
`/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin`
`PATH`的工作原理是，在终端输入一个命令时，shell 会按照以下顺序查找：
1. **检查是否是 shell 内置命令**（如 `cd`, `echo` 等）
2. **如果不是内置命令，就在 PATH 列出的目录中从左到右查找**
3. **找到第一个匹配的可执行文件就执行**
4. **如果所有目录都没找到，就报 "command not found"**
```c
添加方式有三种：
临时添加（当前终端有效）
export PATH=$PATH:/你的/程序/路径

 永久添加（对用户生效）
echo 'export PATH=$PATH:/你的/程序/路径' >> ~/.bashrc
source ~/.bashrc

系统级添加（需要权限）对所有用户有效
sudo echo 'export PATH=$PATH:/路径' >> /etc/profile
```

如果想要实现这样的功能就需要对环境变量修改，有几种方式，也就是临时添加
```
# 临时添加到 PATH（只对当前终端会话有效）
export PATH=$PATH:/path/to/your/program
```
或者是永久添加到家目录里的bashrc或者是bash_profile里,
```
# 添加到 ~/.bashrc 或 ~/.bash_profile
echo 'export PATH=$PATH:/path/to/your/program' >> ~/.bashrc
source ~/.bashrc
```
也可以放到系统标准目录
```
# 需要 root 权限
sudo cp myprogram /usr/local/bin/

# 然后任何人都可以直接运行
myprogram
```

cd为什么是shell内置命令
- `cd` 需要改变当前 shell 进程的工作目录
    
- 如果它是外部程序，改变的是子进程的目录，不会影响父进程（当前 shell）
    
- 所以必须作为 shell 内置命令实现
