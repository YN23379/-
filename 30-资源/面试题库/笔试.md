## c

在c语言中，一个函数不写返回值类型，默认的返回类型是int
这是C语言的一个历史遗留特性,在早期的C语言标准(C89/90)中就是如此规定的。
虽然现代编程实践建议明确声明函数的返回类型,但编译器仍然保持这个默认行为以保证向后兼容性。例如:  
```c
main() { return 0; }  
等价于  
int main() { return 0; }
```


取模运算左右必须是整型
printf的返回值是它成功打印的**字符数量**
浮点数算术标准是 ieee754

**ar**是用于创建、修改和提取静态库文件的标准工具。
它可以将多个目标文件(.o文件)打包成一个静态库文件(.a文件)。使用ar工具可以创建静态库、向库中添加或删除目标文件、列出库的内容等。


如果一个运算里同时有有符号和无符号整数，且两者 **rank 相同**（`unsigned int` 和 `int` 的 rank 相同），则有符号类型会被转换为无符号类型。
即无符号和有符号混合运算时，有符号会转成无符号，导致负数变成非常大的正数。

### 编译链接

**运行时地址和加载地址是程序链接时决定的，运行时地址和加载地址不一定相同**

加载地址是程序被实际加载到内存中的位置  ，运行时地址是程序在执行过程中的实际地址  
它们的关系取决于程序是否支持地址重定位  
在支持虚拟内存的现代操作系统中,往往会使用虚拟地址映射,使得运行时地址和加载地址可以不同

## `c++`
面向对象程序设计语言有三大基本特征:**封装性、继承性和多态性**。
**继承性**允许新类基于已有类创建,新类可以继承原有类的属性和方法,实现代码重用,是面向对象的重要特征之一。
**多态性**使得同一种方法在不同对象上有不同的实现方式,增加了程序的灵活性和可扩展性。
**封装性**是将数据和操作数据的方法封装在一起,对外部隐藏内部细节,只暴露必要的接口,这是面向对象实现信息隐藏的重要机制。



## Linux

ext2是Linux早期的**非日志文件系统**，无日志功能。系统崩溃后需通过fsck长时间检查和修复文件系统。
ext3是Linux下的**日志文件系统**，基于ext2改进，核心特性是添加了日志功能（记录元数据变更），大幅缩短了崩溃后的恢复时间。
ext4是ext3的后续版本，延续了日志功能，并在性能（如支持更大分区/文件、延迟分配）和可靠性上进一步优化，属于日志文件系统。

## 操作系统

波特率指信号每秒的变化次数。比特率指每秒可传输的二进制位数。在无调制的情况下，波特率精确等于比特率。采用调相技术时，波特率不等于比特率。
数字信道传送数字信号的速率称为数据传输速率或比特率。
传输率就是指每秒传输多少位，传输率也常叫波特率。
波特率是指线路状态更改的次数。只有每个信号符合所传输数据的一位时，才等于每秒位数。

### 进程线程

信号量值S的含义：
S > 0：表示有S个资源可用，S个进程可以进入临界区
S = 0：表示资源已被占用，无等待进程
S < 0：|S|表示有|S|个进程正在等待资源


如果系统中有m个进程，则就绪队列中至少有0个进程，因为可能会阻塞

**在时间片轮转的实时操作系统中，任务切换发生在四种核心场景：**
**被动切换**：当进程因资源受限无法继续时（如请求被占用的互斥锁），系统将其转为等待状态并切换任务。
**主动切换**：进程自愿放弃CPU（如调用sleep主动休眠），系统将其置为睡眠态并执行切换。
**强制切换**：包括时间片耗尽时的强制性轮转切换，以及进程被撤销时的资源回收切换。
这四种机制共同构成了实时系统的调度基础——**资源等待、主动让出、时间片到、进程结束**都会触发切换，确保系统的响应性、公平性和资源高效利用。

### 存储
存储器层级速度排序（从快到慢）：
1. **寄存器 (Register)** - CPU内部，最快
2. **缓存 (Cache)** - CPU内部或紧邻CPU
3. **内存 (RAM)** - 主板上的主存
4. **Flash/硬盘/SSD** - 外部存储设备

**缓存一致性**：多核CPU中确保各个核心的缓存数据与主内存保持一致性的机制。当某个核心修改了共享数据时，其他核心的缓存副本需要及时更新或失效，以防止读取到过时的数据。常见的协议有MESI（修改、独占、共享、无效）协议，通过总线监听或目录协议来维护一致性。

**指令缓存**(I-Cache)和**数据缓存**(D-Cache)是L1缓存的分区设计。I-Cache专门存储CPU指令，D-Cache专门存储数据。这种分离设计可以避免指令和数据访问冲突，提高并行性。现代CPU通常采用哈佛架构的缓存设计，允许同时访问指令和数据，提升流水线效率。
[[操作系统#存储器]]

**TLB**（Translation Lookaside Buffer）是页表缓存，用于加速虚拟地址到物理地址的转换。它将最近使用的虚拟页号到物理页帧号的映射关系缓存起来，避免每次地址转换都访问内存中的页表，可以大幅减少内存访问次数，提高地址转换效率。

对缓存友好的代码应满足：
1. **时间局部性**：最近访问的数据很可能再次访问
2. **空间局部性**：相邻的数据很可能一起访问

3. **顺序访问**：尽量连续访问内存
4. **紧凑布局**：减少缓存行浪费
5. **数据重用**：在缓存中复用已加载数据

计算机所能处理的最小的数据项称为位，在很多场景下**字节**是最常用的存储单位,但它并不是最小的数据单位。

## ARM
ARM调用标准（ATPC）中，函数的参数是通过**寄存器或者堆栈**（就是Stack没有Heap）传递
在ARM架构中：
**前4个参数**：通常通过寄存器 R0-R3 传递
**第5个及以后的参数**：通过**栈**传递
**返回值**：通过 R0 返回
**栈指针**：SP寄存器管理栈

ARM处理器中，ARM指令是32位，Thumb指令是16位
ARM状态：执行32位ARM指令集
Thumb状态：执行16位Thumb指令集（代码密度高）
主要区别

│            │ ARM状态     │ Thumb状态   │
├─────────────┼─────────────┼─────────────┤
│ 指令长度   │ 32位        │ 16位        │
│ 代码密度   │ 较低        │ 较高        │
│ 性能       │ 较高        │ 较低        │
│ 应用场景   │ 性能敏感    │ 代码大小敏感│

## 代码

**通过绝对地址调用函数**：
在实际嵌入式开发中，这种技术常用于调用固定地址的固件函数或跳转到Bootloader。

有个函数位于0x20000000处，输入参数为int类型，输出为void类型，调用该函数代码正确的是
((void (*)(int))0x20000000)(int)
typedef void (*func)(int); func a = (func)0x20000000; a(int);
```c
// 定义函数指针类型
typedef void (*func_ptr)(int);
// 将地址转换为函数指针
func_ptr my_func = (func_ptr)0x20000000;
// 调用函数
my_func(789);
```
不需要解引用函数指针，在C语言中函数调用会自动解引用
