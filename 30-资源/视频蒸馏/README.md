# 视频蒸馏

这里保存从视频中提取出的技术路线、学习建议和待核验问题。

视频内容先作为外部观点保存，经过官方文档、源码、实机或项目经验核对后，再提炼到 `20-领域/` 的长期知识笔记。视频中的薪资、行业趋势和个人判断不直接视为事实。

## 处理规则

- 记录原视频链接、作者、发布时间和访问日期。
- 区分视频明确说出的内容、页面章节摘要、评论区观点和自己的延伸解读。
- 对术语转写不确定的地方保留原样，并列入待核验。
- 能转化成学习任务的内容，写入笔记中的“学习建议”和“下一步验证”。
