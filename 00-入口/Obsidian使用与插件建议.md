# Obsidian 使用与插件建议

## 一、已经替你配好的部分（无需动手）

这些写进了 `D:\笔记\.obsidian\`，**重启 Obsidian 后生效**：

| 配置 | 值 | 作用 |
|---|---|---|
| 自动更新内部链接 | 开 | **移动/改名笔记时，指向它的链接自动跟着改**——知识库最重要的一条 |
| 附件默认目录 | `90-附件` | 粘贴/拖入的图片自动进附件目录，不再散落各目录 |
| 新笔记位置 | 当前目录 | 在哪个目录建笔记就落在哪 |
| 链接格式 | `[[wikilink]]` | 全库统一用内链，重命名也不怕 |
| 模板文件夹 | `99-模板` | 命令面板搜 `模板` → 插入模板，直接选现成模板 |
| 书签面板 | 4 组 | 「每天要看／索引／规矩与记录／当前项目／常查知识」，打开就能跳 |
| 关系图配色 | 按分区上色 | 绿=项目、蓝=领域、橙=资源、紫=入口，一眼看清结构 |
| 库内日记插件 | **已关闭** | 因为日报属于工作汇报，已经移到库外 `D:\工作汇报\`，避免误建 |

### 每天真正要用的三个入口

1. **书签面板**（左侧书签图标）→ 点「库总入口」或「看板：待整理」
2. **`Ctrl+O`** → 输入文件名快速打开（文件名都改成短而准的了，好搜）
3. **关系图**（左侧图标）→ 看某篇笔记被谁引用、连到哪

> 反向链接不用自己维护：打开任意笔记，右侧「反向链接」面板会列出**所有指向它的笔记**。

## 二、建议装的社区插件

社区插件要在 **设置 → 第三方插件（Community plugins）→ 浏览** 里搜名字安装。
我不替你装——第三方插件是要在你库里运行的代码，按名字确认作者后再装更稳妥。

### 第一批（强烈建议，装了立刻好用）

| 插件 | 解决什么问题 | 备注 |
|---|---|---|
| **Obsidian Git** | 定时自动 commit 保存 + 推到 GitHub | 你这个库本来就是 git 仓库（remote `YN23379/-`）。装了之后每天自动留版本，改错能回退，也不用记 git 命令 |
| **Homepage** | 启动时自动打开指定笔记 | 设成 `00-入口/README.md`，每次开 Obsidian 直接看到总入口，而不是上次那篇 |
| **Linter** | 一键规范 frontmatter 顺序、空行、标题层级 | 本库有 `type/scope/doc_type/status/evidence/updated` 六个属性，Linter 能保证格式一致 |
| **Advanced Tables** | 表格编辑（自动对齐、Tab 跳格） | 本库里表格很多（矩阵、清单），手写 | 对齐很痛苦 |

### 第二批（看你习惯）

| 插件 | 用途 |
|---|---|
| **Templater** | 比自带模板强：能自动填日期、按目录选不同模板、跑 JS。等模板用熟了再上 |
| **Omnisearch** | 比自带搜索更快，支持模糊匹配。注意：中文检索可用，但**拼音搜索支持不完整** |
| **Excalidraw** | 画图。适合画启动流程、GPIO 三层初始化这类图，比 ASCII 图清楚 |
| **Recent Files** | 侧栏显示最近打开的笔记，切换快 |
| **Iconize**（原 Icon Folder） | 给 `10-项目`/`20-领域` 等目录加图标，文件树更好认 |

### 可以先不装

- **Dataview**：Obsidian 1.9 起自带的 **Bases** 已经能做数据库视图（本库的 `看板-*.base` 就是），
  Dataview 更强但语法要另学，暂时用不上。
- **Smart Connections 之类 AI 插件**：要填 API key，且会把笔记内容发到外部服务，
  这个库里有项目资料，装之前先想清楚。

## 三、为什么这个库现在好用了

重构前：105 篇里 **59 篇完全没有对外链接**，打开一篇就"走进死胡同"。
现在：**286 → 606 条内部引用**，每篇末尾都有「相关」节，每个有 3 篇以上的目录都有导航页。

所以找东西有三条路，任选：

1. **从入口往下走**：README → MOC → 目录导航页 → 具体笔记
2. **横向跳**：任意笔记末尾的「相关」→ 同目录或相关主题
3. **反向查**：右侧反向链接面板 → 谁引用了我
