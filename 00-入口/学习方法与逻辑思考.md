# 学习方法与逻辑思考

> 这是一篇长期维护的个人学习记录。它记录的不是某个领域的知识，而是我如何把输入变成理解、输出和可以继续修正的能力。

## 当前对学习的理解

知识库在大多数时候像百科，主要保存已经整理好的概念、原理、资料和结论。但学习不只是把信息放进知识库，而是不断经历：

```text
输入信息
→ 用自己的话理解
→ 针对信息输出
→ 从输出中发现漏洞
→ 修正理解
→ 再次输出
```

输入提供材料，理解建立解释，输出暴露问题，修正才让理解逐渐稳定。没有输出时，很容易把“看懂了”误认为“掌握了”。

## 当前状态

- 这两个月的输入很多，主要来自视频、文档、课程和已有知识库。
- 对一些内容有自己的理解和消化，但过程不够稳定，也没有留下足够证据。
- 输出明显不足，很少主动用自己的话讲解、写代码、画图或完成一个可复现的小实验。
- 工作日的专注力有限。今天下午 3 点前的状态虽然不完美，但已经接近目前能达到的较好状态。
- 还不清楚自己固定喜欢什么，但能观察到自己会对有结构、反馈清楚、可以逐步掌握的系统产生持续投入。

## 目前的工作假设

### 兴趣可能在投入过程中产生

玩《异星工厂》《幸福工厂》《戴森球计划》或《群星》时，最初不一定已经非常感兴趣，往往是先觉得有一点东西，然后在学习规则、解决问题、看到系统发展后逐渐投入。

因此，“我对什么感兴趣”不一定是开始行动前就能回答的问题。兴趣可能来自：

- 系统有规律，可以逐渐理解；
- 行动后有及时反馈；
- 能看到资源、能力或成果增长；
- 难度不断上升，但暂时仍然可以处理；
- 有一定自主选择空间。

### 精力调整应该先切换任务方式

当一个任务效率很低时，切换不一定要离开当前目标。公司里不能直接去打游戏，可以在同一主题内切换工作方式：

- 阅读文档 → 用自己的话写三句解释；
- 看代码 → 画调用链或数据流；
- 写代码 → 编译运行一个最小例子；
- 调试报错 → 整理现象、假设和验证步骤；
- 学习概念 → 设计一个问题，尝试讲给别人听。

这样切换的是输入、理解、实践和表达之间的模式，同时保留当前任务的方向。

## 最小学习循环

每天不要求写长文，只完成一次最小循环：

```text
今天输入了什么？
我现在认为它为什么成立？
我能不能不用原文讲给别人听？
哪一步我其实还讲不清？
```

输出可以很小：两分钟口述、一个流程图、一个最小代码、一个对比表、一个问题清单，或者一段 100 字的解释。输出的目的不是写得漂亮，而是让不清楚的地方显形。

## 学习记录格式

### 输入

- 材料：
- 来源：
- 我为什么关注它：

### 理解

- 我的解释：
- 它解决什么问题：
- 它为什么成立：
- 一个例子：
- 一个反例或边界：

### 输出

- 我做了什么输出：
- 输出中卡住的地方：
- 哪个概念需要重新查：

### 修正

- 原来的理解：
- 新的理解：
- 修正依据：
- 下一次验证：

## 每周复盘

每周只挑一个重要主题复盘，不追求覆盖全部输入：

1. 本周最值得保留的一个理解是什么？
2. 我用什么方式输出过？
3. 输出暴露了哪个漏洞？
4. 下周要做的最小验证是什么？
5. 哪种任务方式最容易让我进入状态？

每月再把已经反复验证过的内容提炼进对应的领域知识库。没有经过输出和修正的内容，先保留在学习记录或视频蒸馏区，不急着写成确定结论。

## 当前调整方案

- 每天至少完成一次四句式学习循环，不要求超过五分钟。
- 每周至少做一次脱离原文的解释，可以是口述、文字、图或代码。
- 把同一技术主题拆成阅读、解释、实践、调试和复盘几种任务，在效率下降时切换任务方式。
- 用小项目制造反馈，不只依靠继续观看更多视频。
- 记录“什么条件让我愿意继续投入”，不要急于给自己贴固定的兴趣标签。
- 只把经过输出、验证和修正的内容升级为长期知识。

## 长期判断标准

学习是否有效，不先看收藏了多少材料，而看能否：

- 用自己的话解释核心机制；
- 回答“为什么”和“什么时候不成立”；
- 写出或运行一个最小例子；
- 发现自己的解释与实际结果不一致；
- 根据反馈修正原来的理解；
- 在一段时间后重新讲清楚，而不是只在刚看完时记得。

## 2026-09-20 反思记录

这段时间主要完成了输入，理解和消化有一些，但远远不够，输出更少。今天在公司下午 3 点前的专注状态虽然仍有限，但已经是当前状态下相对较好的水平。观察到自己对游戏的兴趣具有阶段性：刚开始往往只是觉得有一点意思，经过学习规则、解决问题和看到发展后会连续投入几周或一个多月，之后兴趣又会下降。

这说明兴趣不是稳定不变的标签，也不一定在行动前就清楚。当前更值得观察的是：什么样的任务结构、反馈速度、难度和自主性会让我愿意继续投入，以及如何在工作中通过切换任务方式维持对同一目标的推进。
