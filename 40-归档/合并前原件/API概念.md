API 是一组明确定义的函数、协议和数据结构的集合，用于不同软件组件之间的通信和交互。它规定了组件如何被调用、需要什么参数、以及返回什么结果，同时隐藏了其内部实现细节。
API是软件组件之间交互的约定和接口。

- **接口函数**：提供服务的函数名称、参数和返回值。
    
- **行为规范**：定义了调用这些函数后的预期行为和结果。
    
- **抽象**：调用者无需关心功能是如何实现的，只需知道如何使用接口
