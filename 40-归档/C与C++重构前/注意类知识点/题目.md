但 `if (1 == a)` 是编程界公认的**防御性编程**习惯，能有效避免双等于写出单等于造成的编译出错的情况


[[20-领域/C与C++/C语言/字长与类型大小.md#内存对齐]]
```c
#include <stdio.h>

struct A {
    char a1;
    short a2;
    double a3;
    long a4;
    char *p1;
};

int main() {
    printf("结构体大小 = %zu 字节\n", sizeof(struct A));
    return 0;
}
```

最大成员对齐值为 4（`double` 虽然自身是 8，但对齐值取 4），结构体总大小必须是 4 的整数倍。  
当前已占用 20 字节，需要补 4 个字节 → 20 + 4 = **24 字节**,
即1+1（对齐）+2+8+4+4+4（对齐）=24字节，第一个对齐的1字节是为了和short对齐，最后对齐的4字节是为了保证**结构体的最终大小** = **最大成员对齐值的整数倍**
