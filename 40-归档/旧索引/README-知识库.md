# 个人嵌入式知识库

这里记录从具体项目中提炼出来、以后仍能复用的知识。它不是某个项目的开发日志，也不以日期为主线。

## 与项目档案的区别

`项目档案`回答：这块板子当时怎么接、怎么编译、执行了什么命令、遇到了什么错误、最后怎么验证。

`知识库`回答：为什么会有这个问题、背后的硬件和软件原理是什么、换一块板子时应该如何判断和排查。

项目档案保留现场细节，知识库提炼方法和原理。两者分开保存，不互相复制。

## 当前分类

- `芯片与平台`：i.MX95资源、异构多核、System Manager、LM、TRDC、时钟和IOMUX。
- `启动与烧录`：Boot ROM、启动镜像、Bin/ELF、UUU、SD/eMMC、remoteproc。
- `RTOS`：FreeRTOS任务、调度、通信、移植和实时性。
- `工具与环境`：SDK获取、编译环境、SSH、SCP和SFTP。
- `嵌入式通用`：脱离i.MX95后仍适用的启动、内存、调试、串口和原理图知识。

## 记录标准

每篇知识至少说明：

1. 要解决什么问题；
2. 概念的英文全称、所在硬件/软件层级和作用；
3. 从输入到结果的过程；
4. 适用于哪些平台，哪些内容只适用于i.MX95或FRDM-IMX95-PRO；
5. 官方资料、源码、原理图或实机验证依据；
6. 常见误区和排查方法。

结论标记为：`官方资料`、`源码确认`、`实机验证`、`待验证`。不要把当前项目中的一次现象直接写成平台普遍规律。

## 来源项目

本知识库的第一批内容来自 `项目档案/FRDM-IMX95-PRO`。项目档案内保留了原始过程和实机证据，知识库内保留提炼后的原理和方法。
